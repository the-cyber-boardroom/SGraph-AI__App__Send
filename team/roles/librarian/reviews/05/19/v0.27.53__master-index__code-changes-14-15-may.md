## New EXISTS Items

### 1. User Share UI v0.4.0 (sender)

**Package:** `sgraph_ai_app_send__ui__share/v0/v0.4/v0.4.0/`
**Phase A (scaffold):** 2026-05-12 | **Phase B complete:** 2026-05-14 (7 sub-commits)
**CI:** `deploy-ui-share.yml` (exists, deployable)

IFD major release — split of the old `sgraph_ai_app_send__ui__user/` into two purpose-built
trees. The share tree is the sender wizard with unified file + secret flows, ephemeral-by-
default UX, and all overlays inlined (no prototype-patch pattern).

Key points:
- 5-step wizard: Upload → Options → Confirm → Encrypt & Upload → Done
- `<upload-step-done>` unified for file and secret modes
- Ephemeral defaults: file (max_views=20, expires=7d), secret (max_views=2, expires=24h)
- No i18n in v0.4.x (en-gb only)
- `_common/` duplicated by design (tools.sgraph.ai extraction is the next milestone)
