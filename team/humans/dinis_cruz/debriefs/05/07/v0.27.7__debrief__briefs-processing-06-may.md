## What Email-FS-lite Is (for context)

Email-FS-lite is a **filing-cabinet protocol** for agents. It lets them leave each other messages (debriefs, handoffs, questions) and track their own tasks in a shared sgit vault. The whole protocol is files in folders — no broker, no daemon, no API. Operations: SEND (write to mailroom + outbox), DELIVER (mv from mailroom to inbox), DONE (mv from inbox to done). One commit per processing cycle. The pull diff is your inbox notification.

The key property that makes it right for SGraph Send: agent identity (`architect.spec`, `dev.villager`, etc.) stays stable across runtime restarts and model upgrades. When a session ends and a fresh runtime picks up, it reads the existing `brief.md` and `notes.md` and continues — the protocol doesn't know or care that the runtime changed.
