**File:** `sgraph_ai_app_send__ui__user/v0/v0.3/v0.3.3/_common/js/components/send-download/send-browse--v0.3.2.js`

| Ask | Change |
|-----|--------|
| **Ask 1 — Write hard-reject on push failure** | `sg.vfs.write` now awaits `vault.push()` before resolving. On any error (saveFile or push), the write promise rejects. Authors can distinguish transient from permanent failures. |
| **Ask 2b — `sg.vfs.read` via postMessage** | `_read`/`_readText` rewritten to use `__sgVfsReadReq` postMessage (strict path matching via `_findEntryStrict`) instead of `fetch()`. Unknown paths resolve with `{ok:false, error:'ENOENT'}`. |
| **Ask 5 — Symmetric TTL (message handles + dismiss)** | `sg.ui.message(text, opts)` now accepts `{ttl}` and returns a handle. `sg.ui.dismiss(handle)` cancels the timer and removes the banner. TTL management is in the parent, not the banner element. |
| **Ask 6 — `sg.sync` namespace** | `sg.sync.status()` returns `{current, serverHasNewer, localHasUnsynced, serverVersion, writable, lastSyncedAt}`. `sg.sync.refresh()` triggers a non-destructive sync (iframe survives). |
| **Follow-up — `sg.vfs.list` strict errors** | Empty list result → `{ok:false, error:'ENOENT', path}`. Iframe `_list` translates to human-readable "No such path: …". |
| **Follow-up — `sg.git.*` deprecation** | All 5 `sg.git.*` methods wrapped in IIFE with one-shot `console.warn('sg.git.* is deprecated…')`. Warning fires once per page load, not per call. |
| **Follow-up — `sg.app.selfPath` dynamic** | `vfsBridgeScript` refactored to `_buildVfsBridgeScript(currentPath)`. Called fresh on every nav event so `selfPath` reflects the current document, not the initial mount point. |

## Architecture note — three state stores

The root structural problem identified in the brief: three independent state stores refreshed on different triggers:

1. Parent bridge `fileList` closure — refreshed on explicit list requests
2. `shell._syncState` — refreshed on pull/push events
3. `vault._headCommitId` / `_namedHeadId` — refreshed by vault internals

**Solution:** `sg-vault-synced` CustomEvent as a shared invalidation signal. Any time vault-shell completes a sync (pull, auto-merge, auto-sync, or explicit refresh), it fires the event. The bridge subscribes and propagates the invalidation to both its own `fileList` and the iframe's cache.
