## What These Briefs Cover

### May 14 (v0.27.41) — 14 Documents

**Vault Hosting Architecture:** Vault collections as zip-portable named primitive. Three density modes (dedicated EC2, multi-container, multi-vault-per-app). EC2 warm pools targeting 10-20s boot. Vault rendering without iframe for published single-app vaults.

**Manager Vault Pattern:** Vaults that manage other vaults. Credential manager vault as first instance — distributes scoped API tokens (OpenRouter, Anthropic, AWS) with quota, expiry, and audit trail.

**Monetisation Pivot:** Pre-auth + micropayments replaces bring-your-own-key. Stripe hold (£5 default), internal ledger, batched settlement. Infographic tool v2 is the first integration point.

**Kubernetes Validation:** Four documents (research briefs + strategy) validate the per-tenant VM choice. Architecture confirmed appropriate for bursty, isolation-sensitive workloads. Strategic positioning material, no new code.

### May 17 (v0.27.43) — 9 Documents

**Infrastructure CLI Expansion:** CLI-native treatment for Fargate (experiment + benchmark), S3 (full CRUD + vim edit + vault wrappers), EC2 container hosts (node-pool primitive, multi-region), Bedrock (full command tree, vault-grounded sessions), IAM (graph discovery, evidence-driven lockdown).

**Observability + Security Posture:** Unified observability REPL (interactive cross-source log investigation). Dynamic credential delivery (STS just-in-time credentials, scope catalogue in vault). IAM graph (discovery → cleanup → CloudTrail evidence → tightening).

**Substrate Strategy:** Substrate spectrum framework (laptop → Lambda → Fargate → EC2 container → dedicated EC2). One-flag substrate selection. Honest assessment that Lambda SnapStart costs make it uncompetitive for many workloads.
