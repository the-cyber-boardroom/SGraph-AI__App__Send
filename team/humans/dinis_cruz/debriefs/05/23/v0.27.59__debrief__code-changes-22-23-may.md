## What Shipped (Code-Verified EXISTS)

### New Route: `/en-gb/app/` — SG/App Hosting Page

**Package:** `sgraph_ai_app_send__ui__vault/v0/v0.2/v0.2.3/en-gb/app/index.html`

A dedicated page for running vault-hosted apps. Boots a global debug event buffer
(`window._appDebug`) and a fetch proxy before mounting three components:
`<app-shell>`, `<app-hud>`, `<app-debug-pane>`.

### `<app-shell>` — 1,154 lines

The main vault app host. Full lifecycle in a single component: parse hash → open vault →
read `app.json` → optional auth intercept → pre-fetch resources → mount iframe + VFS bridge.
No dependency on vault-loader scripts. Handles `_page.json` via inlined PageLayoutRenderer.
Persists vault key to localStorage for reload recovery. Entry form includes a server endpoint
field (default: `dev.send.sgraph.ai`).

### `<app-hud>` — 201 lines

Fixed 48px status bar with vault badge, app title, read-only badge, copy-link button, and
a debug panel toggle. Also handles `sg.ui.message()` toasts from the hosted app iframe.

### Debug Panel — 5 Components

| Component | Purpose |
|-----------|---------|
| `<app-debug-pane>` | Container: collapsible right-edge panel, 4 tabs, auto-collapses when <40px wide |
| `<app-debug-vault-trace>` | Vault lifecycle events |
| `<app-debug-bridge-log>` | VFS bridge message log |
| `<app-debug-app-state>` | app-shell.getDebugState() dump (appJson, entry, iframe status, timing) |
| `<app-debug-network>` | Outbound fetch calls (method, URL, status, ms) |

### Routing Changes

| Change | Impact |
|--------|--------|
| `/#key` now → `/en-gb/app#key` (was `/en-gb/vault/`) | App-shell is now the first-class opener for vaults with keys |
| Falls back to `/en-gb/vault/` if no `app.json` | Vaults without an app still open in the browser |
| "Open App" opens in same tab (was new tab) | vault-header.js |
| `present:true` restored for `_page.json` after auth | Fixes blank-form case for protected app vaults |
