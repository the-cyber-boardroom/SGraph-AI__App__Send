## Executive Summary

No new human briefs arrived today (July 1 folder does not yet exist). The Librarian session
catalogued two code changes that landed on `dev` on June 30, updated the reality document
accordingly, and corrected two date-metadata errors in `vault/index.md`.

The headline change is **`SGSend.staticMode`** — a new flag that lets the same vault-app
HTML run against a plain static file host (GitHub Pages / S3) without any changes to the
app layer. This is off by default; existing vaults are unaffected. The second change is a
critical bug fix: a bare `_embedHelperSrc()` call in the bridge builder (instead of
`this._embedHelperSrc()`) caused a `ReferenceError` on **every** app mount, breaking all
`/en-gb/app/` sessions. The fix is one line; a 9-assertion regression guard prevents
recurrence.

The 2FA end-to-end MVP and Risk Mandate.ai implementation remain the top build priorities.
The `riskmandate.ai` domain question is still **Immediate** priority.
