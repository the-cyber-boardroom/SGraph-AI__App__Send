## Code Change Summary

**Commit `c32bfed6` — `fix(sg-print): print margins now match the preview (WYSIWYG)`**

- **File:** `sgraph_ai_app_send__ui__user/v0/v0.3/v0.3.1/_common/js/sg-print.js`
- **Version:** 1.0.2 → 1.0.3
- **Root cause:** `.sg-print-page { padding: 0.8cm 1.2cm }` (screen) and `@page { margin: 1cm 1.25cm }` (print) were set independently — they disagreed, and 1cm top was cramped.
- **Fix:** Single constant `PAGE_MARGIN = '1.5cm'` used for both `@page margin` and `.sg-print-page padding`. Preview is now WYSIWYG with the printed PDF.
- **Browser-verified?** No — commit note flags "worth a real Save-as-PDF pass." Fix is code-correct; confirmation requires a manual PDF round-trip.
