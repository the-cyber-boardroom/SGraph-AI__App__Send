## What Was Shipped (Commits Not Previously Documented)

### 1. `b3987ba3` — Null-origin crash + EFBIG guard (June 11)

Two independent fixes in one commit plus a brief:

**Null-origin localStorage crash:** `vault-entry.js` was reading `sessionStorage` without
try/catch. In sandboxed iframes (embed protocol child vaults), this threw synchronously,
crashing the auto-open flow. Fixed with try/catch wrappers in three places plus the new
`VaultLoaderStorage.available()` helper for UI code that branches on storage availability.
New test suite: null-origin survival cases in `test__storage.js`.

**EFBIG guard:** `sg.vfs.write` now fails fast with `EFBIG` (exact limit + size) for blobs
> ~3 MB, instead of producing an opaque Lambda 413. `AUTHORING.md` updated with ceiling docs.

**PROPOSED P-269:** A presigned-PUT write path (mirrors the existing presigned-GET read path)
is the only way to lift the 3 MB ceiling past Lambda. Brief:
`team/comms/briefs/06/11/v0.33.21__brief__vault-presigned-put-large-write.md`. Estimated
~half-day. CLI unaffected.

### 2. `68ac5a27` — Blank-app detection broadened (June 11)

Already captured in reality document by the commit itself (it directly updated `reality/ui/index.md`).
Summarised in master index. Key change: the post-load self-check now catches all "app loaded but
painted nothing" cases (visibility, opacity, empty body, zero height), not just `display:none`.
Plus an empty-entry guard so a 0-byte entry file shows a clear host error instead of a blank iframe.

### 3. `0c34e1c9` — `sg.app.writable` parity + Copy button (June 12)

**Writable parity:** `sg.app.writable` now correctly reflects both crypto AND auth tiers.
Fixes the "EREADONLY on audit-log write despite having the full key" symptom. Debug pane now
shows `writableCrypto` + `writableAuth` separately.

**Copy contents button:** `⎘ Copy` added to send-browse file viewer toolbar for textual types
(code, text, markdown, CSV, HTML). Uses clipboard API with fallback. Flashes "✓ Copied" for
1.6 s. Binary types excluded. Lives in send-browse v0.3.3 IFD overlay; vault-browse-edit
picks it up everywhere it renders a file.
