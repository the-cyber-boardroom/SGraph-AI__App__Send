## In five lines

1. The vault API is 29 paths under `/api/vault/`: 13 pointer, 4 presigned, 12 append. Lanes v2 is on `dev.send.sgraph.ai` only.
2. Vaults live on the dev Lambda: sgit's default host is `https://dev.send.sgraph.ai`.
3. sgit 0.27.0 makes no append-lane calls. The vault web makes most of them. The CMS prototype calls no vault endpoint (cl-6.onboarding, 27 Nov). Account B's GitHub tool is not recorded in this repository and is outside my access.
4. I did not find a single record of "the mapping and the changes to the API used by the vault". The nearest records are the 16 Aug SG/API extraction dev pack (its source brief is not in the repo), the 26 Sep SG/API review (unmerged branch), and the 25 Nov lanes v2 work.
5. Two new findings: `write-if-match` is a read followed by a write, not a storage conditional write; and the CLI documents batches as atomic, which the server's batches are not.
