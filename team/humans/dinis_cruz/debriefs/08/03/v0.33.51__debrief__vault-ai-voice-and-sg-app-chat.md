## The three bugs voice exposed

**Recording could never start.** `core/sg-audio` is a *segment* recorder: `startRecording()`
requires an `onSegment` callback and `stopRecording()` returns nothing. I had written `SGVoice`
against a one-shot recorder that does not exist — I checked the export *names* and not the
signatures. Two bugs stacked; only the first was reachable.

**Every transcription 404'd.** Two layers both reached for the vault's *chat* model. A model
that answers questions is not a model that hears them. Transcription now picks only from
audio-capable models (default `google/gemini-3.5-flash`, hard-coded as you asked), and a
non-audio model is refused up front with a message naming one that works.

**Closing the chat killed the button that reopens it.** sg-layout detaches a panel's element
*before* it emits `panel:closed`, so the handler re-queried the DOM, found nothing, parked
nothing, and orphaned the element. Found by reading sg-layout's source, not by guessing.

## Two things you asked for that were judgement calls

**Recording is teal now, not red.** You were right that red read as an alarm — both surfaces
already spend red on failure, so it was competing with the meaning the palette already had.

**App errors say they came from the app.** `[vault-app] index.html — this error is from the
APP's own JavaScript, not the vault platform`, in the console and on the toast. This is what
closes the `[boot] assembling 2 parts` hunt: that failure was **app code inside a vault**, not
this repo. Your console output settled it — `new Function(a + b)` *succeeded*, and the split
lands mid-identifier (`part0` ends `…filter(func`, `part1` starts `tion(f){`). A
`parts.join('\n')` breaks it; `join('')` fixes it. Better still, the >8 KB write ceiling that
forced the split is gone, so the app can be one file again.

## What is NOT verified

- **No iPad run.** The `m4a` pass-through path has never executed against a real recorder.
- **The SG/App chat panel has not been opened in a browser.** Unit-tested and asserted from
  source; nobody has clicked the button.
- **Colours were not viewed** — a hex swap in two stylesheets, checked by reading.

---

## Deliberately not built

- A per-vault **audio model** setting (`models.audio` in `.vault/llm/config.json`) — hard-coded
  on request.
- **CSP egress lockdown** and **Phase 4 minted credentials** — still the two gaps that would
  turn "the vault holds your key" from a convenience into a guarantee.
