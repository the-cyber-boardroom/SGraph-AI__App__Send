## What This Is

A briefing on Hermes Agent and why it matters to SGraph: **Hermes Agent is an open-source, MIT-licensed, self-hosted autonomous AI agent from Nous Research, released in February 2026, whose defining feature is a closed learning loop (it writes a reusable Markdown skill when it solves a task and keeps persistent memory across sessions), with multi-platform messaging, full browser control, multiple execution backends, and model-agnostic LLM support, all with no telemetry and all data on your machine, and the striking thing is how closely it maps onto SGraph's own work, with the one clear gap being that its memory and skills live locally and unencrypted rather than in an encrypted, portable, shareable vault, which is exactly what SG/Vault and SG/Compute would add.** It sets up the integration map (cross-ref: the v0.33.38 hermes-agent-integration service-map brief) and connects to the memory, tools, and compute work (cross-ref: the v0.33.38 ephemeral-chat-and-file-based-memory, tools-execution-control-flow, and url-to-image-threat-analysis briefs). ## What Hermes Agent Is

The summary: **a persistent, self-hosted, open-source agent that gets more capable the longer it runs.**

Hermes Agent was built by Nous Research (the lab behind the Hermes family of open-source language models) and released in late February 2026 under an MIT license. It is self-hosted (Linux, macOS, WSL2, and reportedly even low-cost VPS and Android via Termux), installs via a single command, and is model-agnostic. It is not a copilot or a chatbot wrapper; it runs persistently on your own machine, connects to your messaging accounts, and accumulates memory and skills over time. It has grown very fast (tens of thousands of GitHub stars within weeks, with figures varying by source and date), and Nous has since added MCP support, a desktop GUI preview, and a self-evolution companion.

## The Defining Feature: The Closed Learning Loop

What sets it apart: **it writes its own reusable skills and remembers across sessions.**

When Hermes solves a hard problem, it writes a reusable Markdown skill file, stores the outcome in persistent memory, and adjusts its approach next time, with no manual configuration, using local full-text search and LLM summarisation. The skills use a portable SKILL.md format compatible with an open skills standard (agentskills.io), so they are searchable, shareable, and reusable. This is the same skills-and-memory idea SGraph has been developing, arrived at independently.

## The Capabilities

| Area | Hermes Capability |
|------|-------------------|
| Memory | Persistent across sessions; stored locally (in a hidden home directory) |
| Skills | 40-plus built-in, plus auto-created SKILL.md skills; open standard |
| Messaging | Telegram, Discord, Slack, WhatsApp, Signal, CLI, and more, via one gateway, with voice-memo transcription |
| Browser and web | Search, page extraction, full browser automation (navigate, click, type, screenshot), vision, image generation, text-to-speech |
| Sub-agents | Parallel isolated sub-agents, each with its own conversation and terminal |
| Automations | Built-in cron scheduler delivering to any platform |
| Execution | Local terminal, Docker (hardened container), SSH remote, Modal and Singularity (cloud and HPC) |
| LLM providers | Nous Portal, OpenRouter (200-plus models), any OpenAI-compatible endpoint, local vLLM |
| MLOps | Batch trajectory generation, RL training (Atropos), trajectory export (ShareGPT) |
| Security | Command approval flows, dangerous-pattern blocking, hardened sandboxed containers |
| Privacy and licence | No telemetry, all data local, MIT licensed, auditable and forkable |

## The Gap SGraph Fills

The one clear difference, and the opening: **Hermes keeps its memory and skills locally and unencrypted, and runs on persistent infrastructure.**

Hermes stores all memory and skills on the local machine in plain local storage, which is great for privacy-on-one-box but means the memory and skills are not encrypted at rest in a portable form, not shareable across parties with cryptographic control, not provenance-bearing, and not multi-party. And while Hermes can execute in Docker or on remote or cloud backends, it is not built around disposable, per-task ephemeral compute that is destroyed after each run. These two gaps are exactly what SG/Vault and SG/Compute provide: encrypted, portable, shareable, versioned, provenance-bearing memory and skills, and disposable per-task ephemeral execution (cross-ref: the integration service-map brief).

## Honest Notes

- **Fast-moving and post-cutoff.** Hermes launched after this corpus's general knowledge cutoff and ships rapidly, so specific APIs, versions, and figures should be verified against the current repository before building.
- **Figures vary.** GitHub star counts and platform counts differ across sources; treat them as directional.
- **MIT licence helps.** The permissive licence means SGraph can integrate with, build on, or fork Hermes freely, commercially, with attribution.
- **Not a competitor.** The values and architecture are aligned; the relationship is integration, not rivalry.
