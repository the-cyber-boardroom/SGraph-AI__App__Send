## 1. Orientation

One HTML file, one `<script type="module">`, `"use strict"`. Rough section map:

```
CSS custom properties + panel styles
constants: TOOLS_ORIGIN, VERSION, RELEASES (changelog-as-data), REG (tool registry)
state globals: CHATS/history, INVOCATIONS, audit, STAGE/TOMB, MEMORY, PENDING, CTX…
boot() · instrumentSg() · writer cascade · commitStaged()
loadModels() + model picker
execute() + per-tool logic · vfsRead/vfsStat
memory (memAdd/memoryMessages/…)
composeContext() + renderContext()
markdown renderer (md/mdInline) · preview (inlineHtml/buildSgShim/previewHtml)
llmRequest() + refreshOne/refreshAll (cost reconciliation)
DEFAULT_SYSTEM · systemPrompt() composition
parser (extractJson/knownAction/parseToolCall/extractToolSegments)
chat plumbing (pushUser/pushBot/pushTool, CHATS) · sendChat() — the agent loop
mount() + panel renders · streaming bubble (_mdSeal/_streamMd/updateThinking)
vault listing cascade (listVaultViaVfs/tryLister/listViaTree)
sessions (snapshot/saveSession/restoreSession) · exportChangeSet
toolbar handlers · boot() · window.__wb test seam
```

Conventions worth copying:

- **Changelog as data.** `const RELEASES=[{v,d,items:[…]}…]` renders as an in-app release-notes overlay. The app documents itself.
- **Everything renders from state.** Small `renderX()` functions re-read globals and rewrite `innerHTML`; no framework, no vdom. Fine at this scale because `busy` serializes mutation.
- **The test seam.** Pure functions are exported for external harnesses (Playwright etc.):

```js
window.__wb = { parseToolCall, extractToolSegments, md, buildSgShim, execute,
  memoryMessages, addVaultFileToMemory, memSetLock, getMem:()=>MEMORY,
  mdSeal:_mdSeal, streamMd:_streamMd, streamReset:()=>{_mdSealLen=0;_mdSealHtml="";} };
```

Do this from day one — it costs one line and makes the hard parts (parser, renderer) testable without booting the UI.

## 2. Recipe: typed tool registry + audited dispatcher

### The registry — declare each tool once, with a blast-radius tier

```js
const REG = {
  "vfs.list":   {tier:"READ_ONLY",  params:"path?",         desc:"list known vault files"},
  "vfs.read":   {tier:"READ_ONLY",  params:"path",          desc:"read a file (live vault, or staged)"},
  "vfs.stat":   {tier:"READ_ONLY",  params:"path",          desc:"existence + size + source"},
  "vfs.write":  {tier:"WRITE",      params:"path, content", desc:"stage a write"},
  "vfs.delete": {tier:"DESTRUCTIVE",params:"path",          desc:"stage a delete (tombstone)"},
  "vfs.commit": {tier:"WRITE",      params:"(none)",        desc:"persist staged writes/deletes"},
  "preview.markdown":{tier:"READ_ONLY", params:"path", desc:"render markdown in the Preview panel"},
  "memory.add":    {tier:"WRITE",      params:"name, content", desc:"create/replace a memory item (fails on locked)"},
  "memory.remove": {tier:"DESTRUCTIVE",params:"name",          desc:"delete a memory item (fails on locked)"},
  "skills.list":   {tier:"READ_ONLY",  params:"(none)",        desc:"list available skills with topics + related edges"},
  "skills.load":   {tier:"READ_ONLY",  params:"name",          desc:"load a skill's full guidance"},
  // … skills.search, tools.load/actions/describe, preview.section/iframe, memory.list
};
const TOOLS_OFF = new Set();   // per-tool agent disable (UI checkboxes)
```

The registry is *data*: the prompt's tool section, the Tools panel UI, the audit chips, and the dispatcher all derive from it. Add a tool = add one entry + one `case`.

### The dispatcher — one gate, everything audited

```js
async function execute(action, params, manual){
  params = params || {};
  const def = REG[action];
  const entry = {action, params, tier: def ? def.tier : "?", ok:false, ts:Date.now()};
  let result;
  try {
    if(!def) throw new Error("unknown action");
    if(TOOLS_OFF.has(action) && !manual)
      throw new Error("'"+action+"' is disabled for the agent — re-enable it in the Tool registry");
    switch(action){
      case "vfs.read":  { result = await vfsRead(params.path); break; }
      case "vfs.write": {
        if(!params.path) throw new Error("path required");
        const wc = params.content || "";
        STAGE[params.path] = wc; delete TOMB[params.path];   // stage, don't write
        renderFiles(); renderStaged();
        if(AUTOCOMMIT){
          const c = await commitStaged("auto: write "+params.path);
          result = {path:params.path, bytes:wc.length, committed:c.committed, via:c.via, failed:c.failed};
        } else {
          result = {staged:true, path:params.path, bytes:wc.length,
                    note:"staged — Commit (or enable auto-commit) to persist"};
        }
        break;
      }
      case "vfs.delete": {
        if(!params.path) throw new Error("path required");
        TOMB[params.path] = true; delete STAGE[params.path];  // tombstone
        /* …auto-commit branch as above… */
        break;
      }
      case "skills.load": {
        const idx = await loadSkillsIndex();
        const sk = (idx.skills||[]).find(x => x.name===params.name || x.path===params.name);
        if(!sk) throw new Error("no such skill: "+params.name+" (call skills.list)");
        const content = await readFile(sk.path);
        result = {name:sk.name, description:sk.description, related:sk.related, content};
        break;
      }
      // … one case per registered tool
    }
    entry.ok = true;
  } catch(e){
    result = {error: String(e.message||e)};
    entry.error = result.error;
  }
  entry.result = result;
  entry.preview = summ(result);        // short — for the human audit row
  audit.unshift(entry); renderAudit();
  return result;                        // full — for the model
}
```

### The two-summary rule (critical, easy to get wrong)

```js
const summ = (r)=>{ try{ const s=JSON.stringify(r); return s.length>240 ? s.slice(0,240)+"…" : s; }
                    catch(e){ return String(r); } };
const summFull = (r)=>{ try{ const s=(typeof r==="string")?r:JSON.stringify(r);
                             return s.length>8000 ? s.slice(0,8000)+"…[truncated]" : s; }
                        catch(e){ return String(r); } };
```

`summ` feeds the audit UI; `summFull` feeds the model as the TOOL RESULT. The original bug — feeding the model the 240-char version — makes the agent confidently "summarise" truncated files. If you copy nothing else, copy this distinction. (Improvement worth adding: when `summFull` truncates JSON, say so *inside* valid JSON rather than breaking it mid-structure.)

### Staged reads shadow the store

```js
async function vfsRead(path){
  if(!path) throw new Error("path required");
  if(TOMB[path]) throw new Error("deleted (staged)");
  if(path in STAGE) return {path, source:"staged", content:STAGE[path]};
  const content = await window.sg.vfs.readText(path);
  return {path, source:"vault", content};
}
async function readFile(path){        // the low-level twin used by previews/skills
  if(path in STAGE) return STAGE[path];
  return await window.sg.vfs.readText(path);
}
```

Returning `source: staged|vault` in tool results teaches the model (and shows the user) which layer it is reading.

**⚠ FIX BEFORE REUSE:** deny-list your credential file(s) here (`key.json` in the original is readable by the agent — it can echo the key into the chat and into persisted sessions):

```js
const SECRET_PATHS = new Set(["key.json"]);
if(SECRET_PATHS.has(path)) throw new Error("access to "+path+" is not permitted");
```

<a name="3-parser"></a>
## 3. Recipe: tolerant tool-call parser

The problem: even when the system prompt mandates one exact format, real models emit at least four shapes. The design: **liberal in shape, strict in dispatch** — nothing runs unless it maps to a known action.

### Brace-matching JSON extractor (string- and escape-aware)

```js
function extractJson(text){
  const f = text.match(/```(?:tool|json)?[ \t]*\n?/i);
  const start = f ? f.index + f[0].length : 0;
  const i = text.indexOf("{", start);
  if(i < 0) return null;
  let depth=0, inStr=false, escp=false;
  for(let k=i; k<text.length; k++){
    const ch = text[k];
    if(inStr){
      if(escp) escp=false;
      else if(ch==="\\") escp=true;
      else if(ch==='"') inStr=false;
      continue;
    }
    if(ch==='"'){ inStr=true; continue; }
    if(ch==="{") depth++;
    else if(ch==="}"){ if(--depth===0) return text.slice(i, k+1); }
  }
  return null;   // unbalanced — likely still streaming or prose
}
```

Do not use a regex for this; braces inside JSON strings break naive matchers. This 15-line scanner is the reliable primitive.

### The known-action gate

```js
// ⚠ ORIGINAL — too permissive: the regex arm accepts any made-up verb in a
// known namespace (e.g. "vfs.destroyEverything" passes the gate, then fails
// later as "unknown action" — but in segment extraction it still swallows text).
function knownAction(a){
  if(!a || typeof a!=="string") return false;
  return !!REG[a] || /^(vfs|tools|preview|memory|skills)\.[a-z]+$/i.test(a);
}

// ✅ FIXED — exact registry membership only:
function knownAction(a){ return typeof a==="string" && !!REG[a]; }
```

### The four-shape parser

```js
function parseToolCall(text){
  if(!text) return null;
  let body = text;
  const fence = text.match(/```[ \t]*[a-zA-Z]*[ \t]*\n([\s\S]*?)```/);
  if(fence) body = fence[1];

  // (a) JSON object with an action field — or a bare action token just before it
  for(const src of [body, text]){
    const j = extractJson(src); if(!j) continue;
    let o; try{ o = JSON.parse(j); }catch(_){ continue; }
    if(o && typeof o === "object"){
      if(knownAction(o.action))
        return {action:o.action, params:o.params || o.arguments || o.input || {}};
      // model wrote:  skills.load\n{"name":"vault-authoring"}   (action outside the JSON)
      const pre = src.slice(0, src.indexOf(j));
      const m = pre.match(/([a-zA-Z_][\w]*\.[a-zA-Z_][\w]*)\s*[:=]?\s*$/);
      if(m && knownAction(m[1])){
        const inner = (o.params!=null ? o.params : (o.arguments!=null ? o.arguments : o.input));
        return {action:m[1], params: inner!=null ? inner : o};
      }
    }
  }
  // (b) function-call style:  vfs.read({"path":"docs/README.md"})
  const fc = body.match(/([a-zA-Z_][\w]*\.[a-zA-Z_][\w]*)\s*\(\s*(\{[\s\S]*?\})?\s*\)/);
  if(fc && knownAction(fc[1])){
    let p={}; if(fc[2]){ try{ p=JSON.parse(fc[2]); }catch(_){} }
    return {action:fc[1], params:(p && p.params) ? p.params : p};
  }
  // (c) bare action on its own line, optional JSON after
  const m2 = body.match(/^\s*([a-zA-Z_][\w]*\.[a-zA-Z_][\w]*)\s*$/m);
  if(m2 && knownAction(m2[1])){
    const after = body.slice(body.indexOf(m2[1]) + m2[1].length);
    const rj = extractJson(after);
    let p={}; if(rj){ try{ const po=JSON.parse(rj); p=(po&&po.params)?po.params:po; }catch(_){} }
    return {action:m2[1], params:p};
  }
  return null;   // prose — just show it
}
```

Params are accepted under `params` / `arguments` / `input` because different model families prefer different key names. Note also the accepted key aliases downstream (`skills.search` takes `topic` *or* `query`) — cheap tolerance that prevents stalls.

### Multi-call segmenting (models batch prose + several tool blocks)

```js
function extractToolSegments(text){
  const re = /```[ \t]*[a-zA-Z]*[ \t]*\n?([\s\S]*?)```/g;
  let m, last=0, found=0; const segs=[];
  while((m = re.exec(text))){
    const call = parseToolCall(m[0]);          // parse THIS fenced block alone
    if(call){
      found++;
      const pre = text.slice(last, m.index);
      if(pre.trim()) segs.push({type:"text", text:pre.trim()});
      segs.push({type:"tool", call});
      last = re.lastIndex;
    }
  }
  if(!found) return null;
  const tail = text.slice(last);
  if(tail.trim()) segs.push({type:"text", text:tail.trim()});
  return segs;   // ordered: [text, tool, text, tool, text…]
}
```

**⚠ FIX BEFORE REUSE:** as written, *any* fenced block that happens to parse — including a code block that merely *documents* a tool call — executes. Two tightenings (keep the tolerant single-call fallback for the whole-reply path if you want it):

```js
// 1) In segment extraction, only honour explicitly tagged fences:
const re = /```[ \t]*(tool|json)[ \t]*\n([\s\S]*?)```/g;
// 2) In shape (b), anchor to line start so prose mentioning api.call(...) can't fire:
const fc = body.match(/^\s*([a-zA-Z_][\w]*\.[a-zA-Z_][\w]*)\s*\(\s*(\{[\s\S]*?\})?\s*\)\s*$/m);
```

The system prompt already mandates the ```` ```tool ```` fence, so you lose almost nothing.

## 4. Recipe: bounded agent loop with stop support

```js
async function sendChat(q){
  if(busy || !API_KEY) return;
  q = (q||"").trim(); if(!q) return;

  // auto-title an untouched chat from its first message
  { const c = curChat();
    if(c && c.history.length===0 && /^chat \d+$/.test(c.title)){
      c.title = (q.length>28 ? q.slice(0,28)+"…" : q) || c.title; renderChatTabs(); } }

  const pend = PENDING.slice();                       // one-shot attachments, THIS turn only
  const prior = history.filter(m=>m.role==="user"||m.role==="assistant")
                       .map(m=>({role:m.role, content:m.content}));
  const bounded = (CTX.history===false) ? []
                : (CTX.histLimit>0 ? prior.slice(-CTX.histLimit) : prior);

  const ac = new AbortController(); ABORT=ac; STOP=false;
  busy = true; setBusyUI(true);
  pushUser(q + (pend.length ? ("  📎 "+pend.map(p=>p.name).join(", ")) : ""));

  // attachments become multimodal content parts on the user turn
  let curContent = q;
  if(pend.length) curContent = [{type:"text", text:q}].concat(pend.map(p =>
    p.kind==="image" ? {type:"image_url", image_url:{url:p.content}}
                     : {type:"text", text:"\n=== attached file: "+p.name+" ===\n"+p.content}));
  PENDING.length = 0; renderPending();

  // system message omitted entirely when the composer empties it
  const sysP = systemPrompt();
  let convo = (sysP.trim() ? [{role:"system", content:sysP}] : [])
              .concat(memoryMessages()).concat(bounded)
              .concat([{role:"user", content:curContent}]);

  try {
    for(let step=0; step<6; step++){                  // hard cap: 6 LLM calls / turn
      if(STOP) break;
      startThinking();                                 // streaming bubble
      const d = await llmRequest(convo, "chat", updateThinking, ac.signal);
      stopThinking();
      const inv = d.__inv, text = (d.content||"").trim();
      if(STOP) break;

      // multi-segment path: prose + N tool calls in one reply
      const segs = extractToolSegments(text);
      if(segs){
        convo.push({role:"assistant", content:text});
        let ran=0; const acts=[];
        for(const part of segs){
          if(STOP) break;
          if(part.type==="text"){ if(part.text) pushBot(part.text); }
          else if(ran < 10){                           // cap: 10 tool executions / reply
            const c = part.call; ran++; acts.push(c.action);
            pushTool(`⚙ <b>${esc(c.action)}</b>(${esc(JSON.stringify(c.params||{}))})`);
            const rr = await execute(c.action, c.params);
            convo.push({role:"user", content:"TOOL RESULT ["+c.action+"]: "+summFull(rr)});
          }
        }
        if(inv){ inv.outcome = ran ? ("tool: "+acts.join(", ")) : "reply"; renderLLM(); }
        if(STOP) break;
        if(ran) continue; else break;
      }
      // single-call path
      const call = parseToolCall(text);
      if(call){
        pushTool(`⚙ <b>${esc(call.action)}</b>(${esc(JSON.stringify(call.params||{}))})`);
        convo.push({role:"assistant", content:text});
        const result = await execute(call.action, call.params);
        if(STOP) break;
        convo.push({role:"user", content:"TOOL RESULT ["+call.action+"]: "+summFull(result)});
        continue;
      }
      pushBot(text); break;                            // plain prose → done
    }
  } catch(e){
    stopThinking();
    if(STOP || (e && e.name==="AbortError")){
      // keep what streamed: last invocation still holds the partial content
      const last = INVOCATIONS[0];
      const partial = (last && typeof last.content==="string") ? last.content.trim() : "";
      if(partial) pushBot(partial);
      pushTool('■ <b>stopped by user</b>');
    } else pushBot("error: "+(e.message||e));
  }
  ABORT=null; busy=false; setBusyUI(false); renderContext();
}

function stopRequest(){                                // Send button becomes Stop while busy
  if(!busy) return;
  STOP = true;
  if(ABORT){ try{ ABORT.abort(); }catch(_){} }
}
```

Key ideas to keep:

- **Tool results are ordinary messages** (`"TOOL RESULT [action]: …"` as a user turn). Works on every model, no provider tool-API needed. Trade-off: models trained on native `tool` roles do slightly worse, and tool output re-enters with user authority (prompt-injection amplifier — if your provider supports the `tool` role, capability-detect and prefer it; OpenRouter exposes `supported_parameters` per model).
- **Both caps** (6 steps, 10 tools/reply) are load-bearing: agent loops without hard bounds eventually spin.
- **Stop is three things at once**: abort the in-flight fetch, halt further segments/steps (`STOP` checks between every await), and *keep* the partial content + its cost record. Discarding partials makes Stop feel like data loss.
- **⚠ Improvement:** when the loop exits via the step cap, tell both the user and the model ("step limit reached") — the original exits silently.

## 5. Recipe: SSE streaming + invocation recording + cost reconciliation

### The call

```js
async function llmRequest(messages, kind, onToken, signal){
  const t0 = Date.now();
  const body = {model: MODEL, messages, usage:{include:true}, stream:true};
  let r;
  try {
    r = await fetch("https://openrouter.ai/api/v1/chat/completions", {
      method:"POST",
      headers:{ Authorization:"Bearer "+API_KEY, "Content-Type":"application/json",
                "HTTP-Referer":"https://send.sgraph.ai", "X-Title":"SG Vault Workbench" },
      body: JSON.stringify(body), signal });
  } catch(e){
    if(e && e.name==="AbortError") throw e;
    throw new Error("network: "+(e.message||e));
  }
  if(!r.ok) throw new Error("OpenRouter "+r.status+": "+(await r.text()).slice(0,160));

  let content="", usage=null, genId=null, finish=null, model=MODEL, aborted=false;
  const ct = r.headers.get("content-type") || "";
  try {
    if(r.body && typeof r.body.getReader==="function" && ct.indexOf("text/event-stream")>=0){
      const reader = r.body.getReader(); const dec = new TextDecoder(); let buf="";
      for(;;){
        const rd = await reader.read(); if(rd.done) break;
        buf += dec.decode(rd.value, {stream:true});
        let nl;
        while((nl = buf.indexOf("\n")) >= 0){
          const line = buf.slice(0,nl); buf = buf.slice(nl+1);
          const t = line.trim();
          if(!t || t.charAt(0)===":" || t.indexOf("data:")!==0) continue;  // skip blanks/comments
          const data = t.slice(5).trim();
          if(data === "[DONE]") continue;
          let j; try{ j = JSON.parse(data); }catch(_){ continue; }         // tolerate partial JSON
          if(j.id) genId = j.id;
          if(j.model) model = j.model;
          const ch = j.choices && j.choices[0];
          if(ch){
            const dc = ch.delta && ch.delta.content;
            if(dc){ content += dc; if(onToken){ try{ onToken(content); }catch(_){} } }
            if(ch.finish_reason) finish = ch.finish_reason;
          }
          if(j.usage) usage = j.usage;      // final chunk when usage.include:true
        }
      }
    } else {
      // non-stream fallback (some routes ignore stream:true)
      const j = await r.json();
      const m0 = (j.choices && j.choices[0]) || {};
      content = (m0.message && m0.message.content) || "";
      usage = j.usage||null; genId = j.id||null; finish = m0.finish_reason||null;
      if(onToken && content){ try{ onToken(content); }catch(_){} }
    }
  } catch(e){
    if(e && e.name==="AbortError") aborted = true; else throw e;   // abort keeps partials
  }

  // record the invocation — even when aborted
  const u = usage || {};
  const inv = {
    ts:Date.now(), kind:kind||"chat", model, latencyMs:Date.now()-t0,
    promptTokens:(u.prompt_tokens!=null ? u.prompt_tokens : null),
    completionTokens:(u.completion_tokens!=null ? u.completion_tokens : null),
    cost:(typeof u.cost==="number" ? u.cost : null),
    costSource:(typeof u.cost==="number" ? "openrouter" : null),
    generationId:genId, finish, usage:u,
    request: redactForLog(messages),           // see below
    content };
  if(aborted){ inv.outcome="stopped"; if(!inv.finish) inv.finish="stopped"; }
  INVOCATIONS.unshift(inv); renderLLM(); renderCosts();

  // no cost in the stream → schedule authoritative reconciliation
  if(inv.generationId && inv.cost==null)
    setTimeout(()=>refreshOne(inv.generationId), aborted ? 2000 : 1200);

  if(aborted){ const er=new Error("stopped by user"); er.name="AbortError"; throw er; }
  return {content: inv.content, __inv: inv};
}
```

**⚠ Improvements found in review:** flush the decoder tail after the read loop (a final `usage` chunk without a trailing newline is currently lost), and handle a mid-stream `data: {"error":…}` payload explicitly (currently ignored → empty reply).

### Redaction — keep logs shareable

```js
function redactForLog(messages){
  return messages.map(m=>{
    if(typeof m.content==="string") return {role:m.role, content:m.content};
    const parts = (Array.isArray(m.content)?m.content:[m.content]).map(p=>{
      if(p && p.type==="image_url"){
        const u = (p.image_url && p.image_url.url)||"";
        return {type:"image_url", image_url:{url:"[image omitted from log · ~"+Math.round(u.length/1024)+" KB]"}};
      }
      if(p && p.type==="binary_file") return {type:"binary_file", name:p.name, data_url:"[binary omitted]"};
      return p;
    });
    return {role:m.role, content:parts};

## 6. Recipe: streaming Markdown with sealed-prefix caching

### The base renderer — line-oriented, ~15 lines per block type

```js
function md(src){
  const lines = String(src).replace(/\r/g,"").split("\n");
  const out=[]; let i=0;
  const sep = (l)=>/^\s*\|?[\s:|-]+\|[\s:|-]*$/.test(l) && l.includes("-");   // table separator row
  while(i < lines.length){
    const l = lines[i];
    if(/^```/.test(l)){                                   // fenced code
      const buf=[]; i++;
      while(i<lines.length && !/^```/.test(lines[i])){ buf.push(lines[i]); i++; }
      i++; out.push("<pre><code>"+esc(buf.join("\n"))+"</code></pre>"); continue;
    }
    if(/^\s*#{1,6}\s/.test(l)){                           // heading
      const m=l.match(/^\s*(#{1,6})\s+(.*)$/);
      out.push("<h"+m[1].length+">"+mdInline(m[2])+"</h"+m[1].length+">"); i++; continue;
    }
    if(/^\s*---+\s*$/.test(l)){ out.push("<hr>"); i++; continue; }
    if(/^\s*>\s?/.test(l)){ /* blockquote: consume run of > lines */ }
    if(/^\s*\|.*\|/.test(l) && i+1<lines.length && sep(lines[i+1])){
      /* table: header row + separator + body rows */
    }
    if(/^\s*[-*]\s+/.test(l)){ /* list: consume run of bullets */ }
    if(/^\s*$/.test(l)){ i++; continue; }
    // paragraph: consume until blank line or a block-start
    const buf=[];
    while(i<lines.length && !/^\s*$/.test(lines[i])
          && !/^\s*(#{1,6}\s|>|\||```|---+\s*$|[-*]\s)/.test(lines[i])){ buf.push(lines[i]); i++; }
    if(!buf.length){ buf.push(lines[i]); i++; }
    // ^^ PROGRESS GUARD (the v0.6.4 hang fix): a block-start line not consumed by
    // any branch above — e.g. a table header streamed in before its separator row —
    // renders as prose so `i` ALWAYS advances. Without this: infinite loop, 100% CPU.
    out.push("<p>"+mdInline(buf.join(" "))+"</p>");
  }
  return out.join("\n");
}
```

**The lesson generalises:** any streaming renderer will see *every possible prefix* of valid input. Every branch must make progress on partial constructs. The table-header-without-separator case is the classic trap.

### Inline pass

```js
function mdInline(s){
  s = esc(s)
    // protect code spans FIRST with sentinel chars (\u0001/\u0002 — cannot occur
    // in normal text), so the bold/link rules never fire inside `code`
    .replace(/`([^`]+)`/g, (m,c)=>"\u0001"+c+"\u0002")
    .replace(/\*\*([^*]+)\*\*/g, "<strong>$1</strong>")
    .replace(/\[([^\]]+)\]\(([^)]+)\)/g, '<a href="$2" target="_blank" rel="noopener">$1</a>')
    // then restore the protected spans as <code>
    .replace(/\u0001([^\u0002]+)\u0002/g, (m,c)=>"<code>"+c+"</code>");
  return s;
}
```

**⚠ FIX BEFORE REUSE (XSS):** `esc()` in the original only escapes `& < >` — a link target of `https://x" onclick="…` becomes a live attribute. Required fixes:

```js
// escape quotes too:

  c=>({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;',"'":'&#39;'}[c]));
// and allow-list link protocols:
.replace(/\[([^\]]+)\]\(([^)]+)\)/g, (m,txt,href)=>
  /^(https?:\/\/|\/|#|\.)/i.test(href.trim())

### Sealed-prefix incremental rendering (the v0.6.5 optimisation)

Naive streaming re-parses the whole accumulated reply every frame — O(n) per frame, O(n²) per message. The insight: **completed blocks cannot change**. Everything before the last blank line *outside an open code fence* is final.

```js
let _mdSealLen=0, _mdSealHtml="";      // reset per streamed message (startThinking does this)

// find the byte offset of the last safe cut point
function _mdSeal(text){
  text = String(text==null?"":text);
  let fence=false, seal=0, ls=0;
  for(let p=0; p<text.length; p++){
    if(text[p]==="\n"){
      const line = text.slice(ls,p);
      if(/^```/.test(line)) fence = !fence;              // track open code fences
      else if(!fence && /^\s*$/.test(line)) seal = p+1;  // blank line outside a fence
      ls = p+1;
    }
  }
  return seal;
}

// cache HTML for the sealed prefix; re-parse only the streaming tail
function _streamMd(text){
  text = String(text==null?"":text);
  const seal = _mdSeal(text);
  if(seal > _mdSealLen){
    const seg = md(text.slice(_mdSealLen, seal));        // parse only the NEWLY sealed part
    if(seg) _mdSealHtml = _mdSealHtml ? (_mdSealHtml+"\n"+seg) : seg;
    _mdSealLen = seal;
  }
  const tail = md(text.slice(_mdSealLen));               // the still-changing block
  return _mdSealHtml ? (tail ? _mdSealHtml+"\n"+tail : _mdSealHtml) : tail;
}
```

Correctness argument: `md()` is block-local and blank lines terminate every block type, so cutting at a blank-line boundary yields byte-identical output to a full parse. (This was verified in review with a 600-case random-chunking property test — worth committing as a permanent test if you adopt the pattern.) Works only because a *single* stream renders at a time; make the seal state per-message if you ever render concurrent streams.

## 8. Recipe: file-based memory

Item shape: `{name, kind:"text"|"image", content, mime, bytes, on, lock, source}`.

```js
function memAdd(name, content, kind, mime, source){
  const item = {name, kind:kind||"text", content:content||"", mime:mime||"text/plain",
                bytes:(content||"").length, on:true, lock:false, source:source||"chat"};
  const i = MEMORY.findIndex(m=>m.name===name);
  if(i>=0){   // replace, but PRESERVE the user's on/lock choices
    item.on = MEMORY[i].on!==false; item.lock = !!MEMORY[i].lock;
    item.source = MEMORY[i].source||item.source; MEMORY[i]=item;
  } else MEMORY.push(item);
  renderMemory(); renderContext();
}

function memoryMessages(){                 // how memory enters every request
  const out=[];
  const texts = MEMORY.filter(m=>m.kind==="text" && m.on!==false);
  if(texts.length) out.push({role:"system",
    content:"LLM MEMORY — always-on context files (do not ask the user to re-paste these):\n\n" +
            texts.map(m=>"=== "+m.name+" ===\n"+m.content).join("\n\n")});
  const imgs = MEMORY.filter(m=>m.kind==="image" && m.on!==false);
  if(imgs.length) out.push({role:"user",
    content:[{type:"text", text:"Attached memory images ("+imgs.map(m=>m.name).join(", ")+"):"}]

}
```

The semantics that make it usable:

- **Pause vs remove**: `on:false` keeps the item but skips the next request — cheaper than delete/re-add while tuning context.
- **Lock**: the *agent's* `memory.add`/`memory.remove` handlers check `lock` and refuse; the human UI can still edit. This lets you pin ground-truth files the model cannot overwrite. (`memory.add` from chat: `if(ex && ex.lock) throw new Error("'"+name+"' is locked — cannot update from chat")`.)
- **Sources**: attach a local file/image, pull any vault file by path (`addVaultFileToMemory` → `readFile` so staged edits are included), or let the agent add notes.
- **Memory vs one-shot**: `MEMORY` rides every request and survives Clear; `PENDING` rides exactly one turn. Both appear as composer rows.

  } finally { SAVE_BUSY = false; }
}
```

Because the filename derives from the title, load → work → save naturally overwrites the same file as a *new vault commit* — history lives in the vault's version history, not in timestamped filename clutter. (Corollary to document: two different sessions with the same title collide; rename before saving to branch.)

### Tag inlining (staged edits visible pre-commit)

```js
async function inlineHtml(path, withScripts){
  let html = await readFile(path);                       // staged shadows vault
  const dir = path.includes("/") ? path.slice(0, path.lastIndexOf("/")+1) : "";
  html = await replaceAsync(html, /<link\b[^>]*?href=["']([^"']+)["'][^>]*>/gi, async (m, href)=>{
    if(/^(?:https?:)?\/\//.test(href) || /^data:/.test(href)) return m;      // external: keep
    if(!/stylesheet/i.test(m) && !/\.css(?:\?|$)/i.test(href)) return m;
    try{ return "<style>\n"+await readFile(resolvePath(dir, href))+"\n</style>"; }
    catch(e){ return m; }
  });
  html = await replaceAsync(html, /<script\b[^>]*?src=["']([^"']+)["'][^>]*><\/script>/gi, async (m, src)=>{
    if(/^(?:https?:)?\/\//.test(src) || /^data:/.test(src)) return m;
    if(!withScripts) return "<!-- "+src+" omitted (section mode) -->";
    try{ return "<script>\n"+await readFile(resolvePath(dir, src))+"\n<\/script>"; }
    catch(e){ return m; }
  });
  if(!withScripts) html = html.replace(/<script\b[^>]*>[\s\S]*?<\/script>/gi, "<!-- inline script omitted -->");
  return html;
}

// async replace helper — collect tasks in pass 1, substitute in pass 2
async function replaceAsync(str, re, fn){
  const tasks=[];
  str.replace(re, (m, ...a)=>{ tasks.push(fn(m, ...a)); return m; });
  const vals = await Promise.all(tasks);
  let i=0; return str.replace(re, ()=>vals[i++]);
}
```

### The `window.sg` shim — pre-read + replay

```js
async function buildSgShim(html, dir){
  // 1) find every file the page will ask for at runtime (string literals only)
  const F={};
  const re=/(?:loadCss|loadJs|readText|\bread)\s*\(\s*["']([^"']+)["']/g;
  let m; const wants=new Set();
  while((m=re.exec(html))) wants.add(m[1]);
  // 2) pre-read each (staged layer first), keyed exactly as the page passes it
  for(const x of wants){
    const k=String(x).replace(/^\/+/,"");
    let c=null;
    try{ c=await readFile(k); }catch(_){ try{ c=await readFile(resolvePath(dir,x)); }catch(__){} }
    if(c!=null) F[k]=c;
  }
  // 3) emit a script that defines window.sg backed by the embedded map
  return '<script>(function(){var F='+JSON.stringify(F)+';' +
    'function _rt(p){p=String(p).replace(/^\\/+/,"");return Promise.resolve(F[p]!=null?F[p]:"");}' +
    'function _lc(p){return _rt(p).then(function(css){var s=document.createElement("style");' +
      's.setAttribute("data-sg-loaded",p);s.textContent=css;document.head.appendChild(s);return s;});}' +
    'function _lj(p){return _rt(p).then(function(js){var s=document.createElement("script");' +
      's.setAttribute("data-sg-loaded",p);s.textContent=js;document.head.appendChild(s);return s;});}' +
    'window.sg={loadCss:_lc,loadJs:_lj,' +
      'vfs:{readText:_rt,read:_rt,list:function(){return Promise.resolve([]);}},' +
      'fs:{write:function(){return Promise.resolve();},delete:function(){return Promise.resolve();},' +
          'mkdir:function(){return Promise.resolve();}},' +          // writes are NO-OPS: read-only preview
      'app:{id:"preview"}};})();<\/script>';
}

async function previewHtml(path, withScripts){
  let html = await inlineHtml(path, withScripts);
  if(withScripts){
    const sdir = path.includes("/") ? path.slice(0, path.lastIndexOf("/")+1) : "";
    const shim = await buildSgShim(html, sdir);
    // inject FIRST in <head> so window.sg exists before the page's own scripts run
    if(/<head[^>]*>/i.test(html))      html = html.replace(/<head[^>]*>/i, mm=>mm+"\n"+shim);
    else if(/<html[^>]*>/i.test(html)) html = html.replace(/<html[^>]*>/i, mm=>mm+"\n"+shim);
    else                               html = shim+"\n"+html;
  }
  const ifr = document.createElement("iframe");
  ifr.setAttribute("sandbox", withScripts ? "allow-scripts" : "");
  ifr.srcdoc = html;
  previewPanel.appendChild(ifr);
}
```

**⚠ FIX BEFORE REUSE:** `JSON.stringify(F)` does not escape `</script>` — a previewed file containing that literal terminates the shim script early. One line:

```js
var json = JSON.stringify(F).replace(/</g, "\\u003c");
```

Design rules that make this correct: shim goes **first** in `<head>` (defines `window.sg` before `DOMContentLoaded` handlers); writes are no-ops (a previewed page cannot mutate the store); dynamically-*computed* paths aren't pre-bundled — only string literals — which matches the authored pattern the skill recommends.

## 13. Recipe: ephemeral multi-chat

```js
let CHATS=[], ACTIVE=null, _chatSeq=0;
let history=[];                              // ALIAS of curChat().history — all chat code
                                             // reads/writes one variable

function newChat(title, activate){
  const id = "c"+(++_chatSeq);
  const c = {id, title:title||("chat "+_chatSeq), history:[]};
  CHATS.push(c);
  if(activate!==false){ ACTIVE=id; history=c.history; }
  return c;
}
function curChat(){ return CHATS.find(c=>c.id===ACTIVE) || CHATS[0]; }
function setActiveChat(id){
  if(busy) return;                            // never switch mid-turn
  ACTIVE=id; history=curChat().history;
  renderChat(); renderChatTabs(); renderContext();
}
function closeChat(id){
  if(busy || CHATS.length<=1) return;         // always keep one chat
  const i=CHATS.findIndex(c=>c.id===id); if(i<0) return;
  const wasActive=(ACTIVE===id); CHATS.splice(i,1);
  if(wasActive){ ACTIVE=CHATS[Math.max(0,i-1)].id; history=curChat().history; }
}
function clearActiveChat(){
  const c=curChat(); if(!c) return;
  c.history.length=0; history=c.history;      // truncate IN PLACE — preserves the alias
}
```

What is shared vs per-chat:

| Shared across all tabs | Per-chat |
|---|---|
| MEMORY, MODEL, STAGE/TOMB, INVOCATIONS, audit, costs, vault | conversation history, title |

The invariants that keep the alias safe: `busy` blocks switching/closing mid-turn; `clearActiveChat` truncates in place (`length=0`) instead of reassigning; every switch re-points `history` then re-renders. This is the minimal implementation of *chat-as-ephemeral, memory-as-durable*: conversations are cheap tabs you open and discard; the curated context persists underneath all of them.

<a name="14-security"></a>
## 14. Security hardening checklist (fix before reuse)

Findings from a five-role review of this exact code. If you replicate the patterns, apply these first — they are all small diffs:

| # | Issue | Fix |
|---|---|---|
| 1 | `esc()` doesn't escape quotes → attribute-injection XSS via markdown links and `data-*` attributes built from model output | Escape `"` and `'`; allow-list link protocols (`https?:`, relative, `#`) — code in §6 |
| 2 | `knownAction` regex accepts any verb in a known namespace | Exact `REG` membership only — code in §3 |
| 3 | `extractToolSegments` executes *any* fenced block that parses — including example code the model is merely explaining | Restrict segment scanning to ```` ```tool ````/```` ```json ```` fences; anchor function-call matching to line start — code in §3 |
| 4 | Shim JSON not `</script>`-escaped | `.replace(/</g,"\\u003c")` — §12 |
| 5 | Credential file readable by the agent (`vfs.read("key.json")`) → key can leak into chat + persisted sessions | Deny-list secret paths in `vfsRead`/`readFile`/`allFiles` — §2 |
| 6 | Permission manifest (`app.json`) and the entry file are in their own write grant → prompt-injection → staged self-modification → persistent compromise | Never grant an app write access to its own manifest/entry; enforce host-side |
| 7 | DESTRUCTIVE tier is metadata, not policy — agent-initiated deletes need no confirmation, and auto-commit makes them immediate | Require user confirmation (or a policy flag) for agent-initiated DESTRUCTIVE calls; never auto-commit them |
| 8 | `allow-scripts` iframe with no CSP → unrestricted egress; any injected code can exfiltrate decrypted content | Add a CSP `connect-src` allow-list (host bridge + LLM endpoint only) |
| 9 | Runtime CDN imports without SRI | Vendor the layout component into the vault, or add Subresource Integrity + a local fallback |
| 10 | Loop-cap exhaustion is silent | Surface "step limit reached" to both user and model |

None of these invalidate the *patterns* — they are the last inch of the trust boundary the prototype deliberately deferred.

<a name="15-porting"></a>
## 15. Porting notes

To reuse these recipes outside the SGraph vault context, replace exactly three seams:

1. **Storage bridge** — anywhere you see `window.sg.vfs.readText / writeText / list / mkdir`, substitute your store (OPFS, IndexedDB, a REST backend, a local FS API). Keep the shape: async, path-keyed, feature-detected, with a `readFile()` that lets a staging layer shadow the store.
2. **LLM endpoint** — `llmRequest` speaks the OpenAI-compatible chat-completions dialect with SSE; most providers accept it nearly unchanged. The two-source cost model needs a pricing list (`/models`) and, if available, an authoritative per-call endpoint (`/generation`); otherwise keep estimates and label them.
3. **Layout** — `sg-layout` is any tiling/tab layout component; the only contract used is `getPanelElement(id)`, `getLayout()`, `setLayout(json)`, and a ready event.

Everything else — registry/dispatcher, parser, agent loop, streaming renderer, composer, memory, skills, staging, sessions, preview shim — is plain browser JavaScript with no other dependencies, which is precisely why it fits in one file.
