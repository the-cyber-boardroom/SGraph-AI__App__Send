## What you're building

A new FastAPI Lambda that (a) loads its dependencies from the optimised combined
S3 zip (brief 1) and (b) uses the `Serverless__Fast_API` + `Fast_API__Routes`
patterns (brief 2). Below is the minimum file set and the build/deploy/test loop.
Mirror the User Lambda's layout — that is the proven shape.

---

## Directory layout (mirror `lambda__user/`)

```
sgraph_ai_app_send/lambda__<name>/
├── <name>__config.py                         # constants + pinned dependency list
├── fast_api/
│   ├── Fast_API__<Name>.py                    # subclass of Serverless__Fast_API
│   └── routes/
│       └── Routes__<Domain>.py                # subclass of Fast_API__Routes
├── service/
│   └── Service__<Domain>.py                   # business logic (uses Memory-FS)
├── schemas/
│   └── Schema__<Model>.py                     # Type_Safe request/response models
└── lambda_function/
    ├── lambda_handler__<name>.py              # deps load + app boot + run()
    └── deploy/
        └── Deploy__Service.py                 # subclass of Deploy__Serverless__Fast_API
```

Reuse the **shared** `sgraph_ai_app_send/_for_osbot_aws/Lambda__Dependencies__*`
classes — do not copy them per Lambda.

## The four files you must write

### 1. `<name>__config.py`

```python
from sgraph_ai_app_send import package_name

APP__<NAME>__SERVICE_NAME        = '<service-lambda-name>'         # also used as lambda_name()
APP__<NAME>__FAST_API__TITLE     = '<Title>'
APP__<NAME>__FAST_API__DESC      = '<Description>'

APP__<NAME>__LAMBDA_DEPENDENCIES = ['osbot-fast-api-serverless==v1.33.0',   # pin EVERY version
                                    'memory-fs==v0.40.0'                 ,
                                    # … only what this function imports …
                                    ]

# any headers / env-var names this function uses
HEADER__<NAME>__ACCESS_TOKEN     = 'x-...-access-token'
ENV_VAR__<NAME>__...             = '...'
```

### 2. `lambda_function/lambda_handler__<name>.py`

```python
import os, time
_t_init = time.time()

if os.getenv('AWS_REGION'):                                        # only inside Lambda
    from sgraph_ai_app_send._for_osbot_aws.Lambda__Dependencies__Loader import load_combined_dependency
    from sgraph_ai_app_send.lambda__<name>.<name>__config          import APP__<NAME>__LAMBDA_DEPENDENCIES
    load_combined_dependency('<base-name>', APP__<NAME>__LAMBDA_DEPENDENCIES)   # base-name → S3 object prefix

error = None; handler = None; app = None
try:
    from sgraph_ai_app_send.lambda__<name>.fast_api.Fast_API__<Name> import Fast_API__<Name>
    with Fast_API__<Name>() as _:
        _.setup()
        handler = _.handler()
        app     = _.app()
except Exception as exc:
    if os.getenv('AWS_LAMBDA_FUNCTION_NAME') is None:
        raise
    error = f'CRITICAL ERROR: Failed to start service with:\n\n{type(exc).__name__}: {exc}'

def run(event, context=None):
    if error:
        return error
    return handler(event, context)
```

> The `'<base-name>'` you pass to `load_combined_dependency` (e.g.
> `'sgraph-send-<name>'`) is the S3 object prefix; it must be passed identically
> here and to the Builder in deploy. The package list must be byte-identical in
> both places (the hash is computed from it).

### 3. `fast_api/Fast_API__<Name>.py`

```python
from osbot_fast_api_serverless.fast_api.Serverless__Fast_API import Serverless__Fast_API
from osbot_fast_api_serverless.fast_api.routes.Routes__Info  import Routes__Info
from ...service.Service__<Domain>  import Service__<Domain>
from ...routes.Routes__<Domain>    import Routes__<Domain>     # adjust import path
from ...<name>__config             import APP__<NAME>__FAST_API__TITLE, APP__<NAME>__FAST_API__DESC

class Fast_API__<Name>(Serverless__Fast_API):
    domain_service : Service__<Domain> = None

    def app_kwargs(self, **kwargs):                            # optional — relocate docs under /api/
        kwargs = super().app_kwargs(**kwargs)
        kwargs['docs_url'] = '/api/docs'; kwargs['openapi_url'] = '/api/openapi.json'
        return kwargs

    def setup(self):
        with self.config as _:
            _.name = APP__<NAME>__FAST_API__TITLE
            _.description = APP__<NAME>__FAST_API__DESC
            _.enable_api_key = False                            # per-route auth
        if self.domain_service is None:
            # build your Memory-FS-backed service here
            self.domain_service = Service__<Domain>()
        return super().setup()

    def setup_routes(self):
        self.add_routes(Routes__Info)
        self.add_routes(Routes__<Domain>, domain_service=self.domain_service)
```

### 4. `fast_api/routes/Routes__<Domain>.py`

```python
from fastapi import HTTPException, Request
from osbot_fast_api.api.routes.Fast_API__Routes import Fast_API__Routes
from ...service.Service__<Domain> import Service__<Domain>
from ...schemas.Schema__<Model>   import Schema__<Model>__Create

TAG__ROUTES_<DOMAIN>   = 'api/<domain>'
ROUTES_PATHS__<DOMAIN> = [f'/{TAG__ROUTES_<DOMAIN>}/create',
                          f'/{TAG__ROUTES_<DOMAIN>}/info/{{item_id}}']

class Routes__<Domain>(Fast_API__Routes):
    tag            : str = TAG__ROUTES_<DOMAIN>
    domain_service : Service__<Domain>

    def create(self, request: Schema__<Model>__Create, raw_request: Request) -> dict:
        # self.check_access_token(raw_request)        # add if protected
        return self.domain_service.create(...)

    def info__item_id(self, item_id: str) -> dict:
        return self.domain_service.info(item_id)

    def setup_routes(self):
        self.add_route_post(self.create)
        self.add_route_get (self.info__item_id)
```

### 5. `lambda_function/deploy/Deploy__Service.py`

`Deploy__Serverless__Fast_API` is in `osbot-fast-api-serverless` (available to
you). You only write the overrides. Minimal self-contained skeleton:

```python
from osbot_fast_api_serverless.deploy.Deploy__Serverless__Fast_API import Deploy__Serverless__Fast_API
from ..lambda_handler__<name>          import run
from ...<name>__config                  import APP__<NAME>__LAMBDA_DEPENDENCIES, APP__<NAME>__SERVICE_NAME
from <wherever you put them>.Lambda__Dependencies__Builder import Lambda__Dependencies__Builder   # Appendix A.2 of brief 1

class Deploy__Service(Deploy__Serverless__Fast_API):

    def handler(self):                 # the Lambda entry callable from your handler module
        return run

    def lambda_name(self):
        return APP__<NAME>__SERVICE_NAME

    def lambda_dependencies(self):     # kept for base-class compatibility; combined zip supersedes it
        return APP__<NAME>__LAMBDA_DEPENDENCIES

    def deploy_lambda(self):           # optional override — add folders / env vars here
        with super().deploy_lambda() as _:
            # _.add_folder(<static assets path>)
            # _.set_env_variable('MY_ENV', get_env('MY_ENV'))
            return _

    def upload_combined_dependencies_to_s3(self, force=False):     # the optimisation hook
        builder = Lambda__Dependencies__Builder('<base-name>', APP__<NAME>__LAMBDA_DEPENDENCIES)
        return builder.upload(force=force)
```

If you need SnapStart, add the `enable_snapstart()` / `disable_snapstart()` /
`invoke__snapstart_url()` methods — see brief 1 §7 and brief 2 §5 for the rules
(lazy AWS clients, no STS at init, explicit env vars instead of `account_id()`).

## Build / deploy / test loop

1. **Local test first (no AWS).** Construct `Fast_API__<Name>()` with an
   in-memory storage backend and hit it with `TestClient`. Assert your
   `ROUTES_PATHS__<DOMAIN>` matches the registered routes (mirror
   `test__config_fast_api_routes`). No mocks.
2. **Upload deps:** `Deploy__Service().upload_combined_dependencies_to_s3()` —
   first run uploads, subsequent runs with the same pinned list return
   `status='skipped'`.
3. **Deploy function:** `Deploy__Service().deploy_lambda()` — ships the small app
   zip (deps are NOT in it).
4. **Verify cold start** in CloudWatch: look for the `[deps]` and `[init]` timing
   lines. A `/tmp cache hit` line on the second invocation confirms warm reuse.
5. **(Optional) SnapStart:** `enable_snapstart()` then invoke via the snapstart
   alias URL (see `Deploy__Service.invoke__snapstart_url`).

## Definition of done

- [ ] New Lambda dir mirrors `lambda__user/` layout.
- [ ] `APP__<NAME>__LAMBDA_DEPENDENCIES` pins every version; reused identically in
      handler + deploy.
- [ ] Handler loads deps **before** importing the app, gated on `AWS_REGION`,
      with the local-vs-Lambda `try/except`.
- [ ] App subclasses `Serverless__Fast_API`, sets `enable_api_key=False`, builds
      Memory-FS-backed services in `setup()`, registers routes in
      `setup_routes()`.
- [ ] Route classes follow the `__`→path convention, use Type_Safe schemas, raise
      `HTTPException`, and keep `ROUTES_PATHS__*` in sync.
- [ ] Protected routes call `check_access_token(...)` at the top; public routes
      are deliberately authless.
- [ ] AWS clients built lazily (SnapStart-safe); no STS at init.
- [ ] In-memory tests pass with no mocks; route-set assertion passes.
- [ ] CloudWatch shows single-STS / single-S3 dep load and `/tmp` cache hits on
      warm starts.

## Where to look when something breaks

| Symptom | Likely cause | Where |
|---|---|---|
| `ImportError` on a native wheel at cold start | Builder platform/python/abi ≠ Lambda runtime/arch | brief 1 §3, §8 |
| Cold start 404 fetching deps zip | handler package list ≠ Builder package list (hash mismatch) | brief 1 §2 |
| Route test fails after adding an endpoint | `ROUTES_PATHS__*` not updated alongside `setup_routes()` | brief 2 §6 |
| 502 / opaque failure on every request | exception during init captured into `error` | check CloudWatch for the `CRITICAL ERROR` string |
| STS error during deploy/snapshot | AWS call at init time during SnapStart snapshot | brief 1 §7, brief 2 §5 |
| Stale deps after editing strip logic | strip change doesn't change the hash | redeploy deps with `force=True` |
