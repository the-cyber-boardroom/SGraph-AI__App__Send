# Architect → Dev — Optimised Lambda Dependency Packaging (Combined S3 Zip)

**From:** Architect (Explorer team)
**To:** Backend Dev building new FastAPI Lambda functions
**Version:** v0.27.38
**Date:** 2026-05-20
**Status:** Reference brief — code-verified against the User Lambda
**Part of:** `v0.27.38__architect-to-dev__fastapi-lambda-index.md`

---

## TL;DR

Don't bake heavy Python dependencies into the Lambda function zip and don't use
the stock per-package loader. Instead:

- **Build time:** pip-install the full pinned package list into one directory,
  strip the clutter, zip it once, and upload to a shared S3 bucket under a key
  that includes a hash of the package list (idempotent — same deps ⇒ same key ⇒
  skip if already present).
- **Cold start:** download that **one** zip with a **single STS call + single S3
  GET + single unzip**, then `sys.path.insert(0, …)`. Warm containers reuse the
  `/tmp` extraction and skip the download entirely.

This replaced the stock `osbot_aws.load_dependencies()` which made **one STS call
per package** (~900 ms wasted for 6 packages) and did one serial S3 download +
extraction per package with no warm-container reuse.

The two classes live in `sgraph_ai_app_send/_for_osbot_aws/` and are explicitly
**marked for contribution back to `osbot_aws` once validated in production**, so
treat them as reusable infra, not app code.

> **Self-contained note.** These two classes do **not** exist in any published
> `osbot-*` package — `osbot_aws` only ships the *old* per-package loader
> (`osbot_aws.aws.lambda_.boto3__lambda.load_dependencies`). If you only have the
> `osbot-*` packages and not the SG-Send repo, you must **recreate these two
> classes from the complete source in Appendix A** (bottom of this brief). They
> depend only on the Python stdlib + `boto3`, so they will run anywhere.

## 2. The pinned package list (the single source of truth)

`user__config.py`:

```python
APP__SEND__USER__LAMBDA_DEPENDENCIES = ['fastapi-mcp==0.4.0'                     ,
                                        'httpx==0.28.1'                          ,
                                        'memory-fs==v0.40.0'                     ,
                                        'mgraph-ai-service-cache-client==v0.33.0',
                                        'mgraph-ai-service-cache==v0.14.0'       ,
                                        'osbot-fast-api-serverless==v1.33.0'     ]
```

Rules:
- **Pin every version.** The hash that names the S3 object is derived from this
  list; floating versions would silently reuse a stale zip.
- This list is consumed in two places: the Builder (`upload`) and the Loader
  (`load_combined_dependency('<base_name>', <this list>)`). They must be given the
  **same** list, or the cold-start loader will compute a different hash and 404.

## 3. Build side — `Lambda__Dependencies__Builder`

Key class constants (you will likely need to set these per function):

```python
BASE_BUCKET_INFIX   = 'osbot-lambdas'              # bucket: {account}--osbot-lambdas--{region}
LAMBDA_PLATFORM     = 'manylinux2014_x86_64'       # glibc 2.17 — needed for pydantic-core native wheel
LAMBDA_PYTHON       = '3.13'                        # MUST match your Lambda runtime
LAMBDA_ABI          = 'cp313'
LAMBDA_RUNTIME_PACKAGES = {'boto3','botocore','s3transfer','jmespath','dateutil','six','urllib3'}
```

The flow (`upload(force=False)`):

1. **`combined_name()`** = `f'{base_name}-{sha256(sorted(packages))[:12]}'`
   (e.g. `sgraph-send-user-abc123def456`). `s3_key()` =
   `lambdas-dependencies-combined/{combined_name}.zip`.
2. **Idempotency check** — `head_object` on the key; if it exists and `force` is
   False, return `status='skipped'` without rebuilding. This is what makes deploys
   cheap: identical dep lists never re-upload.
3. **`_build()`** — `pip install --target /tmp/combined-deps-build/{name}
   --platform manylinux2014_x86_64 --python-version 3.13 --implementation cp
   --abi cp313 --only-binary=:all: <packages>`. The `--only-binary=:all:` forces
   manylinux wheels so nothing compiles on the build host.
4. **`_strip()`** removes, in place:
   - every `__pycache__/`
   - every `*.pyc / *.pyo / *.pyi`
   - inside each `*.dist-info/`, everything **except** `METADATA` (kept because
     `importlib.metadata` reads it at runtime)
   - top-level packages already provided by the Lambda runtime
     (`LAMBDA_RUNTIME_PACKAGES`)
   - the `bin/` entry-point scripts directory
5. **`_zip_dir()`** → a single `ZIP_DEFLATED` archive in memory.
6. **`s3.put_object(...)`** to the shared bucket; returns
   `status='uploaded', size_bytes=…`.

> **boto3 here is intentional.** The Builder/Loader use raw boto3 (not osbot-aws)
> because they are slated to become part of osbot-aws. Do not "fix" this to use
> osbot-aws in your copy — keep them as standalone infra so the eventual upstream
> PR is clean.

## 4. Load side — `Lambda__Dependencies__Loader`

```python
def load_combined_dependency(base_name, packages):     # the entry point you call
    name = versioned_name(base_name, packages)         # same hash fn as the Builder
    return Lambda__Dependencies__Loader(name).load()
```

`load()` behaviour (in order):

1. **Not in Lambda?** If `AWS_REGION` is unset → return `None` and do nothing
   (so local tests / non-Lambda contexts import deps from the venv as normal).
2. **Already on `sys.path`?** Return early (idempotent within a container).
3. **`/tmp` cache hit?** If `/tmp/lambdas-dependencies-combined/{name}` exists,
   `sys.path.insert(0, …)` and return — **no S3 call on warm containers.**
4. **Cold path:** one `sts:GetCallerIdentity` → bucket name
   `{account}--osbot-lambdas--{region}` → one `s3:GetObject` → one
   `zipfile.extractall` into `/tmp/...` → `sys.path.insert(0, …)`.

Every step prints a `[deps] … {ms}` line, so cold-start cost is visible in
CloudWatch. Keep these — they are how you prove the optimisation is working.

`sys.path.insert(0, …)` (not `append`) matters: the combined zip wins over
anything else, guaranteeing the pinned versions are imported.

## 5. Wiring it into the handler

`lambda_handler__user.py` — the load happens at **module top level, before any app
import**, gated on `AWS_REGION`:

```python
import os, time
_t_init = time.time()

if os.getenv('AWS_REGION'):                                          # only inside Lambda
    from sgraph_ai_app_send._for_osbot_aws.Lambda__Dependencies__Loader import load_combined_dependency
    from sgraph_ai_app_send.lambda__user.user__config                  import APP__SEND__USER__LAMBDA_DEPENDENCIES
    load_combined_dependency('sgraph-send-user', APP__SEND__USER__LAMBDA_DEPENDENCIES)

error = None; handler = None; app = None                             # pin these names
try:
    from ...Fast_API__SGraph__App__Send__User import Fast_API__SGraph__App__Send__User
    with Fast_API__SGraph__App__Send__User() as _:
        _.setup()
        handler = _.handler()
        app     = _.app()
except Exception as exc:
    if os.getenv("AWS_LAMBDA_FUNCTION_NAME") is None:                # re-raise locally
        raise
    error = f"CRITICAL ERROR: Failed to start service with:\n\n{type(exc).__name__}: {exc}"

def run(event, context=None):
    if error:
        return error
    return handler(event, context)
```

Why this shape:
- **Deps loaded before the app import** — the app's `import fastapi` etc. must
  resolve against the freshly-injected `sys.path`.
- **`try/except` that re-raises locally but captures inside Lambda** — a broken
  cold start returns a readable error string to the caller instead of an opaque
  502, while local tests still fail loudly.
- **`run(event, context)`** is the Lambda entry point handed to AWS.

## 6. Wiring it into deploy

`Deploy__Service` extends `Deploy__Serverless__Fast_API` (from
`osbot-fast-api-serverless`). The combined-zip upload is one method:

```python
def upload_combined_dependencies_to_s3(self, force=False):
    builder = Lambda__Dependencies__Builder('sgraph-send-user',
                                             APP__SEND__USER__LAMBDA_DEPENDENCIES)
    return builder.upload(force=force)
```

The base class's `deploy_lambda()` builds and ships the **function code zip**
(your application only — not the deps). Your deploy sequence is therefore:

1. `upload_combined_dependencies_to_s3()` — ensure the deps zip is in S3.
2. `deploy_lambda()` — ship the (small) function code zip.

`lambda_dependencies()` is still overridden to return the package list for base
class compatibility, but the combined zip is what actually loads at runtime.

## 7. SnapStart interaction (important)

The User Lambda uses **Lambda SnapStart**. `Deploy__Service` has
`enable_snapstart()` / `disable_snapstart()` and a `snapstart` alias with its own
Function URL. Two consequences for dependency loading:

- During **snapshot creation** there are **no AWS credentials**, so any code that
  needs STS/S3 must not run at snapshot time. The dep loader is safe because it is
  gated on `AWS_REGION` and runs during init, but be careful adding your own
  init-time AWS calls — see how `Deploy__Service.deploy_lambda()` sets
  `SEND__STORAGE_MODE=s3` and an explicit bucket name as **env vars** precisely to
  *avoid* STS/`account_id()` calls during snapshot creation.
- boto3 clients should be created **lazily** (after restore), not pinned into the
  snapshot. The app does this by constructing a fresh `S3()` in `setup()`.

If your new function does not need SnapStart, you can skip the alias machinery;
the dependency optimisation works the same with or without it.

## 8. What to change for YOUR function

1. Pick a **`base_name`** (e.g. `'sgraph-send-admin'`, `'my-new-service'`). It
   prefixes the S3 object and keeps functions' dep zips distinct.
2. Define your own `APP__..._LAMBDA_DEPENDENCIES` pinned list in your config.
3. If your runtime/arch differ, set `LAMBDA_PYTHON` / `LAMBDA_PLATFORM` /
   `LAMBDA_ABI` on the Builder to match **exactly** (mismatch ⇒ native-wheel
   `ImportError` at cold start).
4. Call `load_combined_dependency('<your base_name>', <your list>)` at the top of
   your handler, before importing your app.
5. Add `upload_combined_dependencies_to_s3()` to your deploy class (or reuse the
   Builder directly).

---

## 9. Gotchas

- **Hash is over the sorted package list only.** Changing a pin changes the hash
  and triggers a fresh upload — good. But editing the Builder's *strip* logic does
  **not** change the hash; if you change what gets stripped, deploy with
  `force=True` once to overwrite the existing object.
- **`METADATA` must survive stripping** — several libs use `importlib.metadata`
  at import time; deleting all `.dist-info` contents breaks them.
- **Don't add the deps to the function code zip too** — that defeats the purpose
  and risks version skew between the two copies.
- **The `/tmp` budget is 512 MB by default.** The extracted deps live there for
  the container's life. If your dep set is large, raise the function's ephemeral
  storage.
- **First cold start after a new dep list is the slow one** (full S3 GET +
  unzip). Subsequent cold starts in warm-ish fleets hit the `/tmp` cache. The
  `[deps]` log lines tell you which path you're on.

## Appendix A — Complete source (recreate verbatim if you lack the SG-Send repo)

Both files depend only on the Python stdlib + `boto3`. Place them anywhere
importable by your handler (the SG-Send repo keeps them at
`sgraph_ai_app_send/_for_osbot_aws/`). The Loader must be imported first by the
Builder (`from ...Lambda__Dependencies__Loader import versioned_name`), so keep
them in the same package.

### A.1 `Lambda__Dependencies__Loader.py`

```python
# Replaces osbot_aws.aws.lambda_.boto3__lambda.load_dependencies().
# Single STS call. Single S3 download. Single extraction. /tmp warm-cache reuse.

import hashlib
import io
import os
import sys
import time
import zipfile


def _deps_hash(packages):                       # Stable hash of a package list — changes only when deps change
    canonical = '|'.join(sorted(packages))
    return hashlib.sha256(canonical.encode()).hexdigest()[:12]


def versioned_name(base_name, packages):        # Combined zip name: base + hash of package list
    return f'{base_name}-{_deps_hash(packages)}'


def _ms(start):                                 # Milliseconds since start (for cold-start profiling)
    return f'{(time.time() - start) * 1000:.0f}ms'


class Lambda__Dependencies__Loader:
    def __init__(self, combined_name):
        self.combined_name = combined_name      # e.g. 'sgraph-send-user-abc123def456'

    def _account_id(self):
        import boto3
        return boto3.client('sts').get_caller_identity()['Account']

    def _region(self):
        import boto3
        return boto3.session.Session().region_name

    def _bucket_name(self):
        return f'{self._account_id()}--osbot-lambdas--{self._region()}'

    def _s3_key(self):
        return f'lambdas-dependencies-combined/{self.combined_name}.zip'

    def _temp_folder(self):
        return f'/tmp/lambdas-dependencies-combined/{self.combined_name}'

    def load(self):
        if os.getenv('AWS_REGION') is None:                       # Not inside Lambda — skip
            return None

        t0          = time.time()
        temp_folder = self._temp_folder()

        if temp_folder in sys.path:                               # Already loaded in this container
            return f'{self.combined_name} (already in path)'

        if os.path.exists(temp_folder):                           # Extracted in /tmp — warm container reuse
            sys.path.insert(0, temp_folder)
            print(f'[deps] /tmp cache hit — {_ms(t0)}')
            return f'{self.combined_name} (loaded from /tmp cache)'

        import boto3                                              # Single STS call — not per package
        t_sts      = time.time()
        account_id = boto3.client('sts').get_caller_identity()['Account']
        region     = boto3.session.Session().region_name
        bucket     = f'{account_id}--osbot-lambdas--{region}'
        print(f'[deps] STS get_caller_identity — {_ms(t_sts)}')

        t_s3      = time.time()
        s3        = boto3.client('s3')
        response  = s3.get_object(Bucket=bucket, Key=self._s3_key())   # Single S3 download
        zip_bytes = response['Body'].read()
        print(f'[deps] S3 download ({len(zip_bytes)//1024}KB) — {_ms(t_s3)}')

        t_unzip = time.time()
        os.makedirs(temp_folder, exist_ok=True)
        with zipfile.ZipFile(io.BytesIO(zip_bytes), 'r') as zip_ref:   # Single extraction
            zip_ref.extractall(temp_folder)
        print(f'[deps] zip extraction — {_ms(t_unzip)}')

        sys.path.insert(0, temp_folder)
        print(f'[deps] total load — {_ms(t0)}')
        return f'{self.combined_name} (loaded from S3)'


def load_combined_dependency(base_name, packages):                # Drop-in entry point for the handler
    name = versioned_name(base_name, packages)
    return Lambda__Dependencies__Loader(name).load()
```

### A.2 `Lambda__Dependencies__Builder.py`

```python
# Build-time counterpart to Lambda__Dependencies__Loader.
# pip install ALL deps into one dir → strip → zip → upload one zip to S3.
# Content-addressable: S3 key includes a hash of the package list (idempotent).

import hashlib
import io
import os
import shutil
import subprocess
import zipfile

from .Lambda__Dependencies__Loader import versioned_name   # same-package import


class Lambda__Dependencies__Builder:
    BASE_BUCKET_INFIX   = 'osbot-lambdas'                   # bucket: {account}--osbot-lambdas--{region}
    LAMBDA_PLATFORM     = 'manylinux2014_x86_64'            # glibc 2.17 — needed for pydantic-core
    LAMBDA_PYTHON       = '3.13'                             # MUST match Lambda runtime
    LAMBDA_ABI          = 'cp313'                            # cpython 3.13

    LAMBDA_RUNTIME_PACKAGES = {'boto3', 'botocore', 's3transfer', 'jmespath', 'dateutil', 'six', 'urllib3'}

    def __init__(self, base_name, packages):
        self.base_name = base_name                          # e.g. 'sgraph-send-user'
        self.packages  = list(packages)                     # full pinned package list

    def combined_name(self):
        return versioned_name(self.base_name, self.packages)

    def s3_key(self):
        return f'lambdas-dependencies-combined/{self.combined_name()}.zip'

    def _bucket_name(self):
        import boto3
        account_id = boto3.client('sts').get_caller_identity()['Account']
        region     = boto3.session.Session().region_name
        return f'{account_id}--{self.BASE_BUCKET_INFIX}--{region}'

    def _s3_exists(self, s3_client, bucket):
        try:
            s3_client.head_object(Bucket=bucket, Key=self.s3_key())
            return True
        except Exception:
            return False

    def _build(self):                                       # pip install targeting the Lambda platform
        target_dir = f'/tmp/combined-deps-build/{self.combined_name()}'
        if os.path.exists(target_dir):
            shutil.rmtree(target_dir)
        os.makedirs(target_dir)

        subprocess.run(
            ['pip', 'install',
             '--target'        , target_dir            ,
             '--platform'      , self.LAMBDA_PLATFORM  ,
             '--python-version', self.LAMBDA_PYTHON    ,
             '--implementation', 'cp'                  ,
             '--abi'           , self.LAMBDA_ABI       ,
             '--only-binary=:all:'                     ,
             '--quiet'                                 ,
             ] + self.packages,
            check=True
        )
        return target_dir

    def _strip(self, directory):                            # Remove clutter + runtime-provided packages
        for root, dirs, files in os.walk(directory, topdown=True):
            to_delete = []
            for d in dirs:
                if d == '__pycache__':
                    to_delete.append(d)
                elif d.endswith('.dist-info'):              # keep METADATA, delete the rest
                    dist_dir = os.path.join(root, d)
                    for f in os.listdir(dist_dir):
                        if f != 'METADATA':
                            fp = os.path.join(dist_dir, f)
                            (shutil.rmtree if os.path.isdir(fp) else os.remove)(fp)
                elif root == directory and d in self.LAMBDA_RUNTIME_PACKAGES:
                    to_delete.append(d)
            for d in to_delete:
                shutil.rmtree(os.path.join(root, d), ignore_errors=True)
            dirs[:] = [d for d in dirs if d not in to_delete]

            for f in files:
                if f.endswith(('.pyc', '.pyo', '.pyi')):
                    os.remove(os.path.join(root, f))

        bin_dir = os.path.join(directory, 'bin')            # CLI entry-point scripts — not useful in Lambda
        if os.path.isdir(bin_dir):
            shutil.rmtree(bin_dir)

    def _zip_dir(self, directory):
        buf = io.BytesIO()
        with zipfile.ZipFile(buf, 'w', zipfile.ZIP_DEFLATED) as zf:
            for root, dirs, files in os.walk(directory):
                for filename in files:
                    filepath = os.path.join(root, filename)
                    arcname  = os.path.relpath(filepath, directory)
                    zf.write(filepath, arcname)
        return buf.getvalue()

    def upload(self, force=False):                          # Build + upload; skip if already in S3
        import boto3
        bucket = self._bucket_name()
        s3     = boto3.client('s3')

        if not force and self._s3_exists(s3, bucket):
            return dict(status='skipped', combined_name=self.combined_name(),
                        s3_key=self.s3_key(), reason='already exists in S3')

        target_dir = self._build()
        self._strip(target_dir)
        zip_bytes  = self._zip_dir(target_dir)
        shutil.rmtree(target_dir, ignore_errors=True)

        s3.put_object(Bucket=bucket, Key=self.s3_key(), Body=zip_bytes)
        return dict(status='uploaded', combined_name=self.combined_name(),
                    s3_key=self.s3_key(), size_bytes=len(zip_bytes))
```
