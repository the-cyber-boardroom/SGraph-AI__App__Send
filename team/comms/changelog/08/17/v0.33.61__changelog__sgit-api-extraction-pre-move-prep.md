# Changelog — SG/API Extraction Pre-Move Preparation

**version** v0.33.61 · **date** 17 August 2026 · **branch** `claude/sgit-api-extraction-refactor-d7wplm`

## What changed

Preparation for the SG/API extraction (dev pack `v0.33.59__sgit-api-extraction`). **Zero API
behaviour change** — no route, schema, service, header, or status code touched.

1. `Deploy__Service.py` — the `sgraph_ai_app_send__ui__user` import and its `add_folder`
   bundling are now conditional on the package being importable (pack `01` §4, option A).
2. Test relocations out of `tests/unit/lambda__user/` (all still run under `tests/unit` in CI):
   - 2 UI-asset tests → `tests/unit/ui__user/`
   - 3 admin-coupled tests (in-memory Admin FastAPI) → `tests/unit/lambda__user__with_admin/`
3. `test_Routes__Vault__Public.py` — now saves/clears/restores `SGRAPH_SEND__ACCESS_TOKEN`
   in its own setUp/tearDown (was silently depending on another test file clearing it).
4. `test_Fast_API__SGraph__App__Send__User.py` — gained `test__api_docs_served` (coverage
   moved from the relocated UI test).
5. Reality doc `reality/send-api/index.md` — `/join/*` section corrected: routes are orphaned,
   not live.
6. New docs: dev pack files `00`–`04` brought onto this branch, plus new
   `05__deletion-candidates.md`; dev review in `team/roles/dev/reviews/08/17/`.

## Test impact

**Should NOT break (bad failure if they do):**
- Everything. Full `tests/unit` verified locally: **982 passed, 9 skipped, 0 failed** —
  identical totals to before the change. No test was deleted; five were relocated and one
  assertion pair moved between files.

**Intentional structural changes QA should know about:**
- `tests/unit/lambda__user/` shrank from 32 to 27 test files (relocations, not removals).
- New folders `tests/unit/ui__user/` and `tests/unit/lambda__user__with_admin/` exist and
  must be inside any CI test glob (they are, since CI runs `tests/unit`).
- `test__api_docs_still_served` no longer exists under `tests/unit/ui__user/`; its
  replacement is `test__api_docs_served` in `tests/unit/lambda__user/fast_api/`.

**Environment note:** running the suite in a Claude Code cloud sandbox requires unsetting the
injected `AWS_ACCESS_KEY_ID`/`AWS_SECRET_ACCESS_KEY` (they flip `has_aws_credentials()` and
fail ~32 tests that assert the memory backend).
