# Change: Universal Container Image (Phase A) + AWS CFN Templates (Phase B) + Full-Cycle Pipeline (C1)

**version** v0.33.54 · **date** 11 August 2026 · **author** Dev/DevOps (Explorer)
**plan** `team/comms/briefs/08/11/v0.33.54__technical-brief__deployment-phases-a-d.md`

## What changed

1. **Dockerfile** — Lambda Web Adapter extension baked in (`/opt/extensions/lambda-adapter`,
   inert outside Lambda); non-root user `app` (uid 10001); native TLS port moves **443 → 8443**
   (non-root can't bind 443 — host-map `-p 443:8443`); HEALTHCHECK + OCI labels.
2. **`serve.py`** — honours `$PORT` (Cloud Run/Heroku), 8080 fallback; new `resolve_http_port()`.
3. **Login page (UI change)** — `GET /auth/set-cookie-form` now serves a branded SG/Send login
   page (was osbot's generic "Auth Cookie Editor"). `POST /auth/set-auth-cookie` retained,
   osbot-compatible. New file `sgraph_ai_app_send__docker/Routes__Auth__Login.py`.
4. **New `deploy/aws/`** — `lambda.cfn.yml`, `ec2.cfn.yml`, `ecs-fargate.cfn.yml`,
   `ami-pipeline.cfn.yml`, README. All cfn-lint clean. Beta until live-account validation.
5. **New workflow `deploy-full-cycle.yml`** — deploy→smoke→destroy cycle on OIDC
   (needs `AWS_DEPLOY_ROLE_ARN` secret; skips gracefully without it).
6. **New shared smoke suite** — `tests/deploy/targets/test_smoke__deployed_target.py`,
   parametrised by `SG_BASE_URL`/`SG_ACCESS_TOKEN`.
7. **Repo root** — `app.json` + `heroku.yml` (Heroku Deploy-button contract).
