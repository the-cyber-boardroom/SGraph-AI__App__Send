# Changelog — `/en-gb/#<key>` behaves like `/#<key>` (2026-09-09)

**Scope:** vault UI routing (`_common/js/vault-loader/vault-loader-routing.js`, comments in `index.html` / `en-gb/index.html`), tests. No API change.

## Why
`sgit` prints vault links as `https://dev.vault.sgraph.ai/en-gb/#sgit_private_read_…:<vault_id>`. The locale landing discarded any hash and rendered the home page, so a correct key looked broken. Root `/#<key>` was the only hash inbox — a rule introduced when fixing the `/ ↔ /en-gb/` redirect loop (353ef55).

## Change
- The hash-consuming half of `runRoot()` is now `_consumeHashInbox()`, shared by `runRoot()` and `runLanding()`. Same decision on both: save the key verbatim to LS (prefix stripping stays in the shells), save deep-link + release pin, `location.replace('/<locale>/app')` with no hash.
- `_appPathForLocale()` keeps the locale (`/pt-pt/#key` → `/pt-pt/app`); root has no locale segment and still goes to `/en-gb/app`.
- `runLanding()` with **no** hash does nothing — no strip (nothing to strip), no redirect. That is the loop guard: the only redirect out of the landing carries no hash and lands on `/app`, which never redirects back to the landing.

## Side effects considered
- A "stray" hash on `/en-gb/` is now treated as a key (as root always did; routing does not validate). `app-shell` fails it into the entry form with an error instead of the landing silently swallowing it. The landing has no in-page `#anchor` links, so nothing legitimate used a landing hash.
- `location.replace` → no history entry (same as root); Back returns to wherever the user came from.
- `/en-gb#key` without the trailing slash relies on the host's directory redirect (`/en-gb` → `/en-gb/`); browsers carry the fragment across that 301. Not changed here.
- Vault shell (`/en-gb/vault#…`) and peek are untouched — they still strip.

## Tests
- Unit `test__routing_decisions.js`: the "runLanding strips hash" suite is replaced by 7 cases (token, sgit-prefixed credential verbatim, deep link, no hash → no redirect/no strip, bare `#`, `/pt-pt/` keeps locale, root unchanged).
- E2E `test__routing.spec.js` Cell 4: `/en-gb/#token` → `/en-gb/app` + LS; sgit credential verbatim; `/en-gb/` without hash stays (≤ 2 navigations).
- `test__regression__no_locale_redirect_loop.spec.js` and `test__regression__root_hash_inbox_saves.spec.js` unchanged and passing.

**SHOULD break if reverted:** the new Cell 4 tests and the 7 unit cases. **Should NOT break:** the loop regression, the root inbox regression, every other routing cell, all shells.
