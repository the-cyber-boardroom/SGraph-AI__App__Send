# Changelog — Remove the "Secret" option from the v0.3.x user UI

**Version:** v0.27.61
**Date:** 2026-05-25
**Author:** Dev (Claude Code session claude/tender-tesla-AxZJX)
**Trigger:** Dinis — the v0.3.x secret-share flow is incomplete (the `/en-gb/s/` recipient
  page 404s). Remove the "Secret" option from v0.3.x for now; secret returns as a v0.4.x
  launch feature.

---

## Summary

The v0.3.x upload wizard's mode toggle offered **File** and **🔒 Secret**. The Secret flow
is broken (recipient page 404s), so the selector is now **locked to File mode** and the
Secret/Text buttons are hidden. Users see only the file uploader. No secret links can be
created from v0.3.x. The secret feature is untouched in the v0.4.x `__share`/`__open` trees
— it will ship properly with the v0.4.x launch.


## Scope

- **v0.3.x only.** The served `/en-gb/` wizard (final overlay shell is `v0.3.2/en-gb/index.html`).
- v0.4.x `__share`/`__open` secret code is **not** touched.
- The `/en-gb/s/` recipient page is left in place (harmless once no new secrets are created).

## Test impact

- **SHOULD break (good):** none — there are no v0.3.x secret-tab UI tests today.
- **Should NOT break (bad):** the file upload flow. The File branch of `_renderIdle` and
  `_setupListeners` (`if (modeFileBtn)` guard) are unchanged; the patch only forces file
  mode and hides two buttons. Any backend/transfer test must stay green.
