## Why These Are Here

The June 1–4 briefs (skills-as-graph, NHI-2.0, skill-as-projection, semantic-graph for outreach)
assume "meaning through connectivity" and "compatibility through connectivity" as first principles.
Without these source documents, agents working on semantic-graph features lack the intellectual
foundation. Having them in the repo means every agent can read the canonical sources directly.

Cross-references:
- **`thinking-in-graphs`** — foundational for the June 4 `skill-as-projection` brief and all
  semantic-knowledge-graph work (June 10 network-intelligence cluster)
- **`compatibility-through-connectivity`** — foundational for the NHI-2.0 series (June 4) and
  the integration-landscape work (June 10)
- **`lexicon-architecture`** — foundational for the semantic-graph visualisation and data-source-
  mapping work (June 10 network-intelligence cluster)
