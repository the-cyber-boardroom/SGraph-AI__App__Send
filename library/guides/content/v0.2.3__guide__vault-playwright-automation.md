# SG/Vault — Playwright / Programmatic Automation Guide

**Audience:** Claude sessions running Playwright against the vault UI.

This guide covers the JavaScript APIs available inside the vault page for automation.
All snippets run inside `page.evaluate(() => { ... })` unless stated otherwise.

---

## 1. Prerequisites — wait for vault to be ready

Before driving any vault action, wait for the vault to mount:

```javascript
// Playwright: wait until send-browse is mounted and file list is available
await page.waitForFunction(() => {
    const browse = document.querySelector('send-browse');
    return browse && browse.dataSource && typeof browse._openFileTab === 'function';
}, { timeout: 20000 });
```

If the vault requires a key (not already in localStorage from a previous session):

```javascript
// Navigate to vault with key in hash — root inbox saves it and redirects
await page.goto(`http://localhost:10067/#your-vault-key`);
// Then wait for vault-browse-mounted event or the above condition
await page.waitForFunction(() => {
    return document.querySelector('send-browse')?.dataSource != null;
}, { timeout: 20000 });
```

## 2. Open a specific file

### Via the JS API (preferred — no navigation)

```javascript
await page.evaluate((filePath) => {
    const browse = document.querySelector('send-browse');
    if (browse && browse._openFileTab) {
        browse._openFileTab(filePath);   // opens tab, renders file
    }
}, 'wardley-maps/the-strategy-in-seven-wardley-maps.md');
```

Then wait for the file to render:

```javascript
await page.waitForSelector('.sb-file__markdown');
// For images: wait for at least one img with a resolved src
await page.waitForFunction(() => {
    const img = document.querySelector('.sb-file__markdown img');
    return !img || img.src.startsWith('blob:');
});
```

### Via URL deep link (new page load)

```javascript
// Open in current tab (loses vault state if key not in LS)
await page.goto(`http://localhost:10067/#vault-key|wardley-maps/the-strategy.md`);

// Open in new tab (keeps current session)
const newTab = await context.newPage();
await newTab.goto(`http://localhost:10067/#vault-key|wardley-maps/the-strategy.md`);
```

## 3. Print a markdown file → save as PDF

### Option A — Playwright's built-in PDF (best for clean output)

Get the rendered HTML and generate PDF directly without the sg-print popup:

```javascript
// 1. Get the rendered markdown HTML
const htmlContent = await page.evaluate(() => {
    const mdEl = document.querySelector('.sb-file__markdown');
    if (!mdEl) return null;
    // Clone to avoid modifying the live DOM
    const clone = mdEl.cloneNode(true);
    // Resolve any remaining data-md-src (shouldn't be any after blob rewrite)
    return clone.outerHTML;
});

// 2. Also get the print_css if the file has it
const printCss = await page.evaluate(() => {
    const styleEl = document.querySelector('.sb-file__markdown style.md-print-css');
    return styleEl ? styleEl.textContent : '';
});

// 3. Build a standalone HTML page and generate PDF
const printPage = await context.newPage();
await printPage.setContent(`
    <!DOCTYPE html><html><head>
    <meta charset="utf-8">
    <style>
        body { font-family: "DM Sans", system-ui, sans-serif; font-size: 11pt;
               line-height: 1.6; color: #1a1a1a; margin: 2cm 2.5cm; }
        h1,h2,h3 { color: #111; }
        pre { background: #f8f8f8; border: 1px solid #e0e0e0; padding: 0.8em; border-radius: 4px; }
        code { font-family: monospace; font-size: 0.88em; }
        img { max-width: 100%; }
        /* Page breaks */
        .md-pb-marker { display: block; height: 0; page-break-after: always; break-after: page; }
        .md-pb-marker__label { display: none; }
        /* Author's print_css overrides */
        ${printCss.replace(/@media print\s*\{/, '').replace(/\}$/, '')}
    </style>
    </head><body>
    ${htmlContent}
    </body></html>
`);
await printPage.pdf({
    path: 'output.pdf',
    format: 'A4',
    margin: { top: '2cm', bottom: '2cm', left: '2.5cm', right: '2.5cm' }
});
await printPage.close();
```

### Option B — Capture the sg-print popup window

The Print button opens a popup via `SgPrint.printHtml()`. Capture it:

```javascript
// Listen for the popup BEFORE clicking Print
const [popup] = await Promise.all([
    page.waitForEvent('popup'),
    page.evaluate(() => {
        // Click the Print button in the active tab's action bar
        const printBtn = Array.from(document.querySelectorAll('.sb-action-btn'))
            .find(b => b.textContent.trim() === 'Print' || b.innerHTML.includes('🖨'));
        if (printBtn) printBtn.click();
    })
]);

await popup.waitForLoadState('domcontentloaded');

// Generate PDF from the popup (it's already styled for print)
await popup.pdf({ path: 'output.pdf', format: 'A4' });
await popup.close();
```

### Option C — Drive SgPrint directly

```javascript
await page.evaluate((fileName) => {
    const mdEl = document.querySelector('.sb-file__markdown');
    if (mdEl && typeof SgPrint !== 'undefined') {
        SgPrint.printHtml(mdEl.innerHTML, fileName);
    }
}, 'the-strategy.md');
// Then capture popup as in Option B
```

## 4. Open App Mode programmatically

### In the CURRENT tab (same session)

The `sg-app-banner.activate()` lifts the current file's content to full viewport:

```javascript
await page.evaluate(() => {
    const banner = document.querySelector('sg-app-banner');
    const content = document.querySelector('.sb-file__content');
    if (banner && typeof banner.activate === 'function') {
        banner.activate(content);
    }
});

// Wait for App Mode to be active (banner becomes visible)
await page.waitForFunction(() => {
    const banner = document.querySelector('sg-app-banner');
    return banner && banner.style.display !== 'none';
});
```

Exit App Mode:
```javascript
await page.evaluate(() => {
    const banner = document.querySelector('sg-app-banner');
    if (banner && typeof banner.deactivate === 'function') banner.deactivate();
});
```

### In a NEW tab (clean app view, no vault chrome)

```javascript
const key = await page.evaluate(() =>
    typeof VaultLoaderStorage !== 'undefined' ? VaultLoaderStorage.getCurrentKey() : ''
);
const filePath = 'wardley-maps/the-strategy-in-seven-wardley-maps.md';
const appUrl = `http://localhost:10067/#${encodeURIComponent(key)}|app:${encodeURIComponent(filePath)}`;

const appTab = await context.newPage();
await appTab.goto(appUrl);

// Wait for the app iframe to appear and load
await appTab.waitForSelector('.sb-file__html-frame', { timeout: 15000 });
// OR for markdown app mode (sg-app-banner lifted)
await appTab.waitForFunction(() => {
    const banner = document.querySelector('sg-app-banner');
    return banner && banner.style.display !== 'none';
}, { timeout: 15000 });
```

## 5. Print the app — current state & options

> **PROPOSED — does not exist yet as a built-in button.**
>
> There is no "Print App" button currently. The `sg-app-banner` hides the vault chrome
> and lifts the file content, but adds no print control of its own.

### What you CAN do via Playwright today:

#### Print a lifted HTML iframe (App Mode with an HTML file)

```javascript
// Get the iframe in App Mode
const appFrame = await page.frameLocator('.sb-file__html-frame');

// Option 1: Print from within the iframe
await page.evaluate(() => {
    const iframe = document.querySelector('.sb-file__html-frame');
    if (iframe && iframe.contentWindow) {
        iframe.contentWindow.print();
    }
});
// Then capture the browser print dialog or use page.pdf()

// Option 2: Generate PDF directly from the iframe's URL
const iframe = page.frame({ url: /blob:/ });
if (iframe) {
    await iframe.page().pdf({ path: 'app-output.pdf', format: 'A4' });
}

// Option 3: Get the iframe content and generate a clean PDF
const iframeHtml = await page.evaluate(() => {
    const f = document.querySelector('.sb-file__html-frame');
    try { return f.contentDocument.documentElement.outerHTML; } catch (_) { return null; }
});
// Build a new page from the HTML and pdf() it
```

#### Print a lifted markdown file (App Mode with a .md file)

Markdown App Mode still has the `.sb-file__markdown` div in the DOM (it's just 
visually lifted). Use Option A from section 3 above — the content is accessible.

## 6. Quick reference — key selectors and APIs

| What | How |
|------|-----|
| Send-browse component | `document.querySelector('send-browse')` |
| Open file tab | `browse._openFileTab('path/to/file.md')` |
| Rendered markdown | `document.querySelector('.sb-file__markdown')` |
| App mode banner | `document.querySelector('sg-app-banner')` |
| Activate App Mode | `banner.activate(contentEl)` |
| Deactivate App Mode | `banner.deactivate()` |
| HTML app iframe | `document.querySelector('.sb-file__html-frame')` |
| Current vault key | `VaultLoaderStorage.getCurrentKey()` |
| Print popup | `SgPrint.printHtml(html, filename)` |
| Deep-link URL | `/#key\|path/to/file` or `/#key\|app:path/to/file` |
| Vault events | `window.sgraphVault.events.on('vault-opened', fn)` |
| Vault events (emit) | `window.sgraphVault.events.emit('event-name', data)` |

### Key vault events to wait on

| Event | Fires when |
|-------|-----------|
| `vault-opened` | Vault decrypted, file list available |
| `vault-browse-mounted` | send-browse rendered, `_openFileTab` safe to call |
| `vault-locked` | Vault locked (navigating away or timeout) |

```javascript
// Playwright: wait for vault-browse-mounted via event
await page.evaluate(() => new Promise(resolve => {
    if (document.querySelector('send-browse')?.dataSource) {
        resolve();   // already mounted
    } else {
        window.sgraphVault.events.on('vault-browse-mounted', resolve);
    }
}));
```
