# SG/Vault — Playwright / Programmatic Automation Guide

**Audience:** Claude sessions running Playwright against the vault UI.

> **Verified against live hosted vault (May 2026).** Where this guide contradicts
> earlier assumptions, the verified finding is shown. See §7 Gotchas for a summary
> of common mistakes.

All Python snippets use `playwright.sync_api`. JavaScript snippets run inside
`page.evaluate(() => { ... })` unless stated otherwise.

---

## 0. One-time environment setup

```bash
pip3 install playwright --break-system-packages -q
python3 -m playwright install chromium   # binary in $PLAYWRIGHT_BROWSERS_PATH
```

Chromium may already be present at `/opt/pw-browsers` — check before reinstalling.
Always launch with `args=["--no-sandbox"]` (required in this container):

```python
browser = p.chromium.launch(args=["--no-sandbox"])
ctx = browser.new_context(viewport={"width": 1440, "height": 1000})
```

## 1. Connection model — hosted vault vs local dev server

### Hosted vault (share token URL)

The production and dev vaults are accessed via a share token in the URL hash:

```
https://dev.vault.sgraph.ai/#sand-ford-9624
                              └── share token ──┘
```

- This is **not** `localhost:10067`.
- The token is **not** a full `passphrase:vault-id` vault key — it is a share token
  that the vault derives into credentials client-side.
- The key is persisted to `localStorage` (`sg-vault-key`) after first load, so a
  second page in the same browser context can reuse the session without re-entering
  the token.
- The `*.sgraph.ai` domains are on the container allow-list, so they load directly.

### Local dev server

```
http://localhost:10067/#your-vault-key
```

Use whichever is appropriate for your session. The JS API surface is identical.

### Expected 403s (non-fatal)

Expect 3 noisy 403s on startup:
- `_common/js/build-info.js`
- `dev.tools.sgraph.ai` web-component scripts (`sg-llm-request`, `sg-layout`)

These are non-fatal — the core viewer renders fine without them. Don't treat them
as failures.

## 2. Open the vault and wait for decrypt

The loader sits on "Loading Vault / Opening vault…" for ~7–9 s while it decrypts.
Poll until `send-browse` is mounted rather than using a fixed sleep.

```python
URL = "https://dev.vault.sgraph.ai/#sand-ford-9624"   # or localhost:10067/#key

p = sync_playwright().start()
browser = p.chromium.launch(args=["--no-sandbox"])
ctx = browser.new_context(viewport={"width": 1440, "height": 1000})
page = ctx.new_page()
page.goto(URL, wait_until="domcontentloaded", timeout=60000)

# Best signal: send-browse is mounted AND _openFileTab is callable
page.wait_for_function("""() => {
    const b = document.querySelector('send-browse');
    return b && b.dataSource && typeof b._openFileTab === 'function';
}""", timeout=30000)
```

Or in JS (Playwright Node):

```javascript
await page.goto('https://dev.vault.sgraph.ai/#sand-ford-9624');
await page.waitForFunction(() => {
    const browse = document.querySelector('send-browse');
    return browse && browse.dataSource && typeof browse._openFileTab === 'function';
}, { timeout: 30000 });
```

You can also wait for the `vault-browse-mounted` event instead of polling:

```javascript
await page.evaluate(() => new Promise(resolve => {
    if (document.querySelector('send-browse')?.dataSource) {
        resolve();   // already mounted
    } else {
        window.sgraphVault.events.on('vault-browse-mounted', resolve);
    }
}));
```

## 3. Open a specific file

### Via the JS API (preferred — no tree navigation needed)

`_openFileTab` opens the file directly. You do **not** need to expand the folder
in the tree first — the tree can be completely collapsed.

```python
FP = "wardley-maps/the-strategy-in-seven-wardley-maps.md"
page.evaluate("(fp) => document.querySelector('send-browse')._openFileTab(fp)", FP)
```

Or in JS:

```javascript
await page.evaluate((filePath) => {
    const browse = document.querySelector('send-browse');
    if (browse && browse._openFileTab) browse._openFileTab(filePath);
}, 'wardley-maps/the-strategy-in-seven-wardley-maps.md');
```

### Wait for the file to render — use visible text, not the selector

> ⚠️ **`waitForSelector('.sb-file__markdown')` is unreliable.** The hidden README
> tab also has `.sb-file__markdown` in the DOM, and it will resolve before your
> file's tab is visible.

Wait on unique visible text from the document instead:

```python
page.wait_for_selector("text=The Strategy in Seven Maps", timeout=15000)
page.wait_for_timeout(4000)  # let decrypted blob images fully decode
```

Or more explicitly in JS:

```javascript
// Wait until the rendered text from YOUR file is visible (not any hidden tab)
await page.waitForFunction(() => {
    const pane = [...document.querySelectorAll('.sb-file__content')]
        .find(e => e.offsetParent !== null);  // visible pane only
    return pane && pane.textContent.includes('The Strategy in Seven');
}, { timeout: 15000 });
// Give blob image decoding a moment
await page.waitForTimeout(4000);
```

### Verified-present APIs

| API | Status |
|-----|--------|
| `send-browse._openFileTab(path)` | ✅ works, preferred |
| `send-browse.dataSource` | ✅ present once mounted |
| `SgPrint` (global) | ✅ present (but **unreliable** for PDF — see §4) |
| `VaultLoaderStorage.getCurrentKey()` | ✅ present |
| `window.sgraphVault.events` | ✅ present |
| `sg-app-banner` (App Mode) | ✅ present |

## 4. Export a markdown file to PDF

> ⚠️ **The `SgPrint` popup approach (clicking Print, capturing popup) does NOT
> work reliably in headless.** The popup opens as `about:blank`, calls
> `window.print()`, and the blob image URLs do not cross into the new window.
> The result is a 1-page near-empty PDF. Use the rebuild method below instead.

### The only verified reliable method — rebuild the doc and inline images

Vault images are decrypted as `blob:` URLs that only exist in the current page.
To survive outside the page they must be rasterised to data-URIs. Carry the full
stylesheet set over by extracting from `document.styleSheets` (not just the
per-file `md-print-css` element — many documents don't have one).

```python
EXTRACT = r"""
async () => {
  // Find the VISIBLE content pane (offset != null = not in a hidden tab)
  const panes = [...document.querySelectorAll('.sb-file__content')];
  let pane = panes.find(e => e.offsetParent !== null && /Strategy in Seven/.test(e.innerText||''))
          || panes.find(e => /Strategy in Seven/.test(e.innerText||''));
  if (!pane) return {error:'no pane'};

  const clone = pane.cloneNode(true);

  // Rasterise each blob: image → data URI so it survives in a new page/file
  const live  = [...pane.querySelectorAll('img')];
  const cimgs = [...clone.querySelectorAll('img')];
  for (let i = 0; i < live.length; i++) {
    try {
      const c = document.createElement('canvas');
      c.width  = live[i].naturalWidth;
      c.height = live[i].naturalHeight;
      c.getContext('2d').drawImage(live[i], 0, 0);
      cimgs[i].setAttribute('src', c.toDataURL('image/png'));
      cimgs[i].removeAttribute('srcset');
    } catch(e) {}
  }

  // Collect ALL stylesheets — includes @media print rules.
  // Do NOT rely solely on style.md-print-css — many documents don't have one.
  let css = '';
  for (const s of document.styleSheets) {
    try { for (const r of s.cssRules) css += r.cssText + '\n'; } catch(e) {}
  }

  return { html: clone.outerHTML, css, imgCount: live.length };
}
"""
data = page.evaluate(EXTRACT)
# For wardley-maps/the-strategy-in-seven-wardley-maps.md: expect imgCount == 8

doc = f"""<!doctype html><html><head><meta charset='utf-8'><style>
{data['css']}
html, body {{ margin: 0; padding: 0; background: #fff; }}
/* Un-collapse the scroll container so all content is visible */
.sb-file__content {{
  position: static !important; height: auto !important;
  max-height: none !important; overflow: visible !important;
  display: block !important; width: auto !important;
  padding: 0 !important; background: #fff !important; color: #111 !important;
}}
.sb-file__content * {{ overflow: visible !important; }}
img {{ max-width: 100% !important; height: auto !important; }}
</style></head><body>{data['html']}</body></html>"""

pg2 = ctx.new_page()
pg2.set_content(doc, wait_until="networkidle", timeout=60000)
pg2.emulate_media(media="print")      # honours .md-pb-marker { break-after: page }
pg2.wait_for_timeout(1500)
pg2.pdf(
    path="output.pdf",
    format="A4",
    print_background=True,
    margin={"top": "14mm", "bottom": "14mm", "left": "14mm", "right": "14mm"}
)
browser.close()
p.stop()
```

**Expected output for `the-strategy-in-seven-wardley-maps.md`:** 17 pages, A4,
all 8 maps embedded, page breaks honoured, front-matter badge hidden.

### QA the PDF

```bash
pdfinfo output.pdf | grep Pages             # verify page count
pdftoppm -png -r 80 -f 6 -l 6 output.pdf page6  # eyeball a page with a map
```

### Why `emulate_media('print')` matters

The `.md-pb-marker` CSS rule uses `break-after: page` under `@media print`. Without
`emulate_media('print')`, the page-break markers are rendered as dashed rules
(screen style) and no actual page breaks appear.

## 5. Open App Mode programmatically

### In the CURRENT tab (same session)

```javascript
await page.evaluate(() => {
    const banner  = document.querySelector('sg-app-banner');
    const content = document.querySelector('.sb-file__content');
    if (banner && typeof banner.activate === 'function') {
        banner.activate(content);
    }
});

// Wait for App Mode to be active (banner becomes visible)
await page.waitForFunction(() => {
    const banner = document.querySelector('sg-app-banner');
    return banner && banner.style.display !== 'none';
});
```

Exit App Mode:
```javascript
await page.evaluate(() => {
    const banner = document.querySelector('sg-app-banner');
    if (banner && typeof banner.deactivate === 'function') banner.deactivate();
});
```

### In a NEW tab (clean app view, key from localStorage)

```javascript
// /en-gb/app#path — hash = file path (NOT vault key)
// Key comes from localStorage (set when vault was first opened via /#vault-key)
const filePath = 'wardley-maps/the-strategy-in-seven-wardley-maps.md';
const appUrl = `http://localhost:10067/en-gb/app#${encodeURIComponent(filePath)}`;

const appTab = await context.newPage();
await appTab.goto(appUrl);

// Wait for App Mode to activate (sg-app-banner becomes visible)
await appTab.waitForFunction(() => {
    const banner = document.querySelector('sg-app-banner');
    return banner && banner.style.display !== 'none';
}, { timeout: 15000 });
```

## 6. Print the app — current state

> **PROPOSED — no built-in Print button in App Mode yet.**

### For a markdown file in App Mode

The `.sb-file__markdown` div is still in the DOM (just visually lifted). Use the
rebuild method from §4 — it works identically whether or not App Mode is active.

### For an HTML iframe in App Mode

```javascript
// Option 1: print from within the iframe
await page.evaluate(() => {
    const iframe = document.querySelector('.sb-file__html-frame');
    if (iframe && iframe.contentWindow) iframe.contentWindow.print();
});

// Option 2: extract the iframe HTML and build a standalone PDF
const iframeHtml = await page.evaluate(() => {
    const f = document.querySelector('.sb-file__html-frame');
    try { return f.contentDocument.documentElement.outerHTML; } catch (_) { return null; }
});
// Build a new page from the HTML and page.pdf() it
```

## 7. Quick reference — key selectors and APIs

| What | How |
|------|-----|
| Send-browse component | `document.querySelector('send-browse')` |
| Open file tab | `browse._openFileTab('path/to/file.md')` |
| Vault ready check | `browse.dataSource && typeof browse._openFileTab === 'function'` |
| Visible content pane | `.find(e => e.offsetParent !== null)` on all `.sb-file__content` |
| Rendered markdown | `.sb-file__markdown` inside the visible pane |
| App mode banner | `document.querySelector('sg-app-banner')` |
| Activate App Mode | `banner.activate(contentEl)` |
| Deactivate App Mode | `banner.deactivate()` |
| HTML app iframe | `document.querySelector('.sb-file__html-frame')` |
| Current vault key | `VaultLoaderStorage.getCurrentKey()` |
| Open in App Mode (new tab) | `/en-gb/app#path/to/file` — hash = file path, key from LS |
| Share/deep-link URL | `/#key\|path/to/file` → root inbox saves key to LS |
| Vault events | `window.sgraphVault.events.on('vault-opened', fn)` |

### Key vault events to wait on

| Event | Fires when |
|-------|-----------|
| `vault-opened` | Vault decrypted, file list available |
| `vault-browse-mounted` | send-browse rendered, `_openFileTab` safe to call |
| `vault-locked` | Vault locked (navigating away or timeout) |

## 8. Gotchas — verified pitfalls

| Pitfall | What happens | Fix |
|---------|-------------|-----|
| Using `SgPrint` popup for PDF | Popup is `about:blank`; blob images don't cross windows; get ~1-page empty PDF | Use the rebuild method (§4) |
| `waitForSelector('.sb-file__markdown')` | Matches the hidden README tab first; hangs or returns wrong content | Wait on visible text, or filter by `offsetParent !== null` |
| Relying on `style.md-print-css` | Many docs have no per-file print CSS; selector returns null | Extract from `document.styleSheets` (all rules) |
| `page.pdf()` on the whole app page | App's scroll container collapses under print → ~1 KB blank PDF | Rebuild content in a standalone page first (§4) |
| Using `page.emulate_media('print')` after `page.pdf()` | The call sequence matters; `emulate_media` must come before `pdf()` | Call `emulate_media('print')` then `wait_for_timeout(1500)` then `pdf()` |
| Clicking tree nodes to expand | Node is in DOM but not visible if folder is collapsed → click fails | Use `_openFileTab(path)` directly — no expansion needed |
| `localhost:10067/#key\|path` deep links | Only valid against a local dev server | For hosted vault, use token URL + `_openFileTab` |
| Fixed `wait_for_timeout` after `goto` | Decrypt is ~7–9 s but variable | Poll for `send-browse.dataSource` instead |
